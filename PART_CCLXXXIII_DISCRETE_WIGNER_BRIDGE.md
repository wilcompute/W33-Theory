## Phase Space over GF(3)

The phase space for two qutrits (d = 3, n = 2) is the 4-dimensional vector space over the field GF(3):

$$\Omega = \mathrm{GF}(3)^4, \qquad |\Omega| = 3^4 = 81$$

The Hilbert space is $\mathcal{H} = (\mathbb{C}^3)^{\otimes 2}$ with dimension $d^n = 9$.

The **standard symplectic form** on GF(3)^4 is the alternating bilinear form:

$$\langle \mathbf{u}, \mathbf{v} \rangle = u_0 v_2 + u_1 v_3 - u_2 v_0 - u_3 v_1 \pmod{3}$$

A fundamental property: since the form is alternating ($\langle \mathbf{u}, \mathbf{u} \rangle = 0$ for all $\mathbf{u}$), **every** projective point in PG(3,3) is isotropic. This explains why the symplectic polar space W(3,3) coincides with all of PG(3,3):

$$|\mathrm{PG}(3,3)| = \frac{3^4-1}{3-1} = 40 = V \qquad \checkmark$$

## Discrete Wigner Function

The **discrete Wigner function** of a density matrix $\rho$ is:

$$W_\rho(\boldsymbol{\alpha}) = \frac{1}{d^n} \mathrm{Tr}[\rho \cdot A(\boldsymbol{\alpha})], \qquad \boldsymbol{\alpha} \in \mathrm{GF}(3)^4$$

where the **phase-point operators** are:

$$A(\boldsymbol{\alpha}) = D(\boldsymbol{\alpha}) \, A(\mathbf{0}) \, D(\boldsymbol{\alpha})^\dagger, \qquad A(\mathbf{0}) = \frac{1}{d^n} \sum_{\boldsymbol{\beta}} D(\boldsymbol{\beta})$$

Key properties:

| Property | Formula |
|---|---|
| Normalization | $\sum_{\boldsymbol{\alpha}} W_\rho(\boldsymbol{\alpha}) = 1$ |
| Real-valued | $W_\rho(\boldsymbol{\alpha}) \in \mathbb{R}$ |
| Marginalization | $\sum_{\mathbf{p}} W_\rho(\mathbf{q},\mathbf{p}) = \langle \mathbf{q} \| \rho \| \mathbf{q} \rangle$ |
| Phase-point trace | $\mathrm{Tr}[A(\boldsymbol{\alpha})] = 1$ |
| Orthogonality | $\mathrm{Tr}[A(\boldsymbol{\alpha}) A(\boldsymbol{\beta})] = d^n \delta_{\boldsymbol{\alpha}\boldsymbol{\beta}}$ |

The minimum possible Wigner function value for $d = 3$, $n = 2$ is:

$$W_{\min} = -\frac{d-1}{d^{2n}} \cdot \frac{d^n+1}{2} = -\frac{2}{81} \cdot 5 = -\frac{10}{81}$$

## Hudson's Theorem and Wigner Negativity

**Hudson's theorem** (Gross 2006, Appleby 2005) for odd prime $d$:

> A pure state $|\psi\rangle$ has $W_{|\psi\rangle}(\boldsymbol{\alpha}) \geq 0$ for all $\boldsymbol{\alpha}$ **if and only if** $|\psi\rangle$ is a **stabilizer state**.

Consequences:

- **Stabilizer states** ($W \geq 0$): classical simulation possible via Gottesman-Knill
- **Magic states** ($W < 0$ somewhere): resource for universal quantum computation
- **Wigner negativity** $W_\neg(\rho) = \sum_{\boldsymbol{\alpha}: W(\boldsymbol{\alpha})<0} |W(\boldsymbol{\alpha})|$ is a magic monotone
- $\mathrm{Sp}(4,\mathrm{F}_3)$ preserves Wigner non-negativity: the automorphisms of W(3,3) preserve the classical/quantum boundary
