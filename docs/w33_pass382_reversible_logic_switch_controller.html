Scope boundary

This isolated controller contains no actual header flag, Q6 edge, route, or physical-oscillator binding. Its edge-step wrap is a controller-frame convention, not a Q6 path closure. Pass 380 owns the actual scheduler phase-lift result; this display neither refines nor binds that map.

Two certified maps, with different roles

T controller successor

The reversible sequence clock moves through the three-operation word and advances the edge-step index only at a latch.

T(edge,0)=(edge,1) T(edge,1)=(edge,2) T(edge,2)=(edge+1 mod 16,0)

Certified: exact order 48, one 48-state reachable orbit, and a two-sided inverse.

P phase clock

The free C3 action rotates the phase position within an edge-step index; it is not the controller successor.

P(edge,phase)=(edge,phase+1 mod 3)

Certified: 16 free three-state phase orbits. P differs from T on exactly the latch phase; the maps fail to commute on FLIP and LATCH states.
