This page records exact finite-code and finite-geometry results from the Pass 4592–4615 continuation. It deliberately separates proven code embeddings from group-order or physical interpretations.

1. Two self-orthogonal axes become one 63-coordinate code

The cubic line/double-six incidence matrix has rank six over F2. Its row and column images are C36=[36,6,16] and C27=[27,6,12]. Both evaluate the same vector x in a six-dimensional minus quadratic space. Concatenating the evaluations for the same x gives

This is the binary six-dimensional simplex code; its dual is the Hamming code [63,57,3]. Its 63 coordinates are the 63 nonzero vectors of F26. The old 27+36 split is exactly the nonzero-singular / anisotropic partition of the minus quadratic form.

2. Exact hexacode-to-Golay bridge

Choose a compatible F43 structure on the same six binary dimensions. The standard hexacode is [6,3,4]4 with weight enumerator 1+45z4+18z6. Concatenate each F4 symbol with the binary inner simplex [3,2,2]. The resulting binary code is [18,6,8] with 1+45z8+18z12.

The repository's explicit cyclic extended Golay construction contains a six-generator subcode that vanishes on six positions. Restricted to the other eighteen coordinates, it is mapped word-for-word to the concatenated hexacode by an explicit frozen coordinate permutation.

paired cubic axes → [63,6,32] simplex → chosen F4 structure → hexacode → [18,6,8] → G24.

3. The Golay ambient code reconstructs the MOG sextet

The 45 weight-eight words of that six-dimensional section are Golay octads. On the eighteen active positions every point occurs in twenty of the 45 octads. Pair frequencies are ten on exactly eighteen pairs and eight on the other 135. The frequency-ten graph is six disjoint triangles, recovering the six binary inner-code triples.

The subcode is identically zero on six Golay coordinates. Exhausting all 720 bijections from those six positions to the six recovered triples gives exactly one assignment for which the resulting six tetrads form a Golay sextet: every union of two tetrads is a Golay octad.

Evidence boundary
