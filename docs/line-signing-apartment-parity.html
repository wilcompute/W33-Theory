Line signings, building apartments, and the parity code

Passes 4461–4465 · exact finite-combinatorial frontier · W(3,3) and general GQ(s,t)

1. The signing is incidence-native

Assign one sign σℓ∈{±1} to each of the 40 geometric lines of W(3,3). Each K4 line owns six point-collinearity edges, and the 40 six-edge supports partition all 240 edges. If N is point–line incidence, the signed adjacency is

Aσ = N diag(σ) Nᵀ − diag(Nσ).

The first moments are exact: tr(Aσ²)=480 and tr(Aσ³)=24 Σℓ σℓ. Any 20/20 balanced line signing therefore has zero cubic trace.

2. The 1,620 quadrangles are the Levi apartments

The point graph has exactly 1,620 induced quadrangles. Each uses four distinct geometric lines; those four lines form a 4-cycle in the dual line graph, and inserting the line vertices gives the corresponding Levi 8-cycle. These are three shadows of the same rank-two-building apartment.

tr(Aσ⁴) = 12000 + 8 W₄ = 24960 − 25920 f₄

Here W₄ is the sum of the four-line sign products over the 1,620 apartments, and f₄ is the fraction with negative product. The fourth moment’s entire variable part is therefore an apartment-parity observable.

3. Exact random baseline

Under independent random line signs, the apartment products are distinct quartic Walsh characters. This gives a closed-form control distribution rather than a Monte-Carlo benchmark:

E W₄ = 0 Var(W₄) = 1620 E W₄³ = 12960 E W₄⁴ = 9891720 E f₄ = 1/2 SD(f₄) = 1/(2√1620)

The null is not exactly Gaussian: standardized skewness is about 0.198761598 and excess kurtosis about 0.769135802.

4. Apartment incidence and tomography

Let H be the 40×1,620 line/apartment incidence matrix and A* the dual W33 line-collinearity adjacency. Exact pair counts give

H Hᵀ = 156 I + 21 A* + 6 J spec(H Hᵀ) = 648¹ ⊕ 198²⁴ ⊕ 72¹⁵.

Modulo two, HHᵀ=A*. More strongly, rankF₂(H)=39 and ker(Hᵀ)=⟨140⟩. Thus all 1,620 apartment parities recover the 40 line signs up to the unavoidable global reversal σ↦−σ.

5. The nondegenerate binary core

The apartment-parity image is a binary [1620,39] linear code. The dual adjacency form has rank 10 over F₂, so the code radical has dimension 29 and the quotient is a nondegenerate 10-dimensional alternating, hence symplectic, vector space.

dim C = 39 dim rad(C) = 29 dim C/rad(C) = 10.

A one-line code generator has weight 162. The XOR of two line generators has weight 270 when the two lines intersect and 312 when they are disjoint.

6. The theorem extends to every generalized quadrangle

For a finite GQ(s,t), set n=(s+1)(st+1), L=(t+1)(st+1), and d=s(t+1). A sign on each geometric line gives:

tr(Aσ²) = n d tr(Aσ³) = 6 C(s+1,3) Σℓ σℓ tr(Aσ⁴) = n d(2d−1) + 24 L C(s+1,4) + 8 WQ.

The exact number of induced quadrangles is Q=n s²t²(t+1)/8. If H is line–quadrangle incidence in that GQ, a line lies in r=(s+1)s²t²/2 quadrangles, intersecting line pairs in α=s²t, and disjoint line pairs in β=s(s+1)/2, so

H Hᵀ = (r−β) I + (α−β) A* + β J.

The dual pair GQ(3,9) and GQ(9,3) both have Q=102,060 quadrangle observables, while their line-sign registers have 280 and 112 bits respectively. Duality preserves the apartment count, not the signing granularity. This is why the general trace theorem does not resurrect the refuted claim that Ramanujan probability is controlled by s alone.
