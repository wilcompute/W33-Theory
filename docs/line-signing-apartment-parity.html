Line signings, building apartments, and the parity code

Passes 4461–4471 · exact finite-combinatorial frontier · W(3,3), protected H10, and general GQ(s,t)

1. The signing is incidence-native

Assign one sign σℓ∈{±1} to each of the 40 geometric lines of W(3,3). Each K4 line owns six point-collinearity edges, and the 40 six-edge supports partition all 240 edges. If N is point–line incidence, the signed adjacency is

Aσ = N diag(σ) Nᵀ − diag(Nσ).

The first moments are exact: tr(Aσ²)=480 and tr(Aσ³)=24 Σℓ σℓ. Any 20/20 balanced line signing therefore has zero cubic trace.

2. The 1,620 quadrangles are the Levi apartments

The point graph has exactly 1,620 induced quadrangles. Each uses four distinct geometric lines; those four lines form a 4-cycle in the dual line graph, and inserting the line vertices gives the corresponding Levi 8-cycle. These are three shadows of the same rank-two-building apartment.

tr(Aσ⁴) = 12000 + 8 W₄ = 24960 − 25920 f₄

Here W₄ is the sum of the four-line sign products over the 1,620 apartments, and f₄ is the fraction with negative product. The fourth moment’s entire variable part is therefore an apartment-parity observable.

3. Exact random baseline

Under independent random line signs, the apartment products are distinct quartic Walsh characters. This gives a closed-form control distribution rather than a Monte-Carlo benchmark:

E W₄ = 0 Var(W₄) = 1620 E W₄³ = 12960 E W₄⁴ = 9891720 E f₄ = 1/2 SD(f₄) = 1/(2√1620)

The null is not exactly Gaussian: standardized skewness is about 0.198761598 and excess kurtosis about 0.769135802.

4. Apartment incidence and tomography

Let H be the 40×1,620 line/apartment incidence matrix and A* the dual W33 line-collinearity adjacency. Exact pair counts give

H Hᵀ = 156 I + 21 A* + 6 J spec(H Hᵀ) = 648¹ ⊕ 198²⁴ ⊕ 72¹⁵.

Modulo two, HHᵀ=A*. More strongly, rankF₂(H)=39 and ker(Hᵀ)=⟨140⟩. Thus all 1,620 apartment parities recover the 40 line signs up to the unavoidable global reversal σ↦−σ.

5. The nondegenerate binary core

The apartment-parity image is a binary [1620,39] linear code. The dual adjacency form has rank 10 over F₂, so the code radical has dimension 29 and the quotient is a nondegenerate 10-dimensional alternating, hence symplectic, vector space.

dim C_ap = 39 dim rad(C_ap) = 29 dim C_ap/rad(C_ap) = 10.

A one-line code generator has weight 162. The XOR of two line generators has weight 270 when the two lines intersect and 312 when they are disjoint.

6. The trace theorem extends to every generalized quadrangle

For a finite GQ(s,t), set n=(s+1)(st+1), L=(t+1)(st+1), and d=s(t+1). A sign on each geometric line gives:

tr(Aσ²) = n d tr(Aσ³) = 6 C(s+1,3) Σℓ σℓ tr(Aσ⁴) = n d(2d−1) + 24 L C(s+1,4) + 8 WQ.

The exact number of induced quadrangles is Q=n s²t²(t+1)/8. If H is line–quadrangle incidence in that GQ, a line lies in r=(s+1)s²t²/2 quadrangles, intersecting line pairs in α=s²t, and disjoint line pairs in β=s(s+1)/2, so

H Hᵀ = (r−β) I + (α−β) A* + β J.

7. Correction to the recent Pass 4433 cycle statistic

The Pass 4433 helper claimed to list every simple 4-cycle once. On W33 it actually emits 3,480 records: 1,740 underlying simple C₄s, each twice. Those 1,740 split into the 1,620 induced apartments plus 120 cycles wholly inside the geometric K₄ lines.

Line-internal cycles always have positive parity under a line signing, so Pass 4433's raw fraction was a diluted apartment fraction:

flegacy = (27/29) fapartment on W(3,3).

This does not invalidate its standardized z-score against a random line-signing baseline; multiplying every sample by the same positive factor leaves z unchanged. In general, flegacy = Q/(Q+3L C(s+1,4)) fapartment. The dilution factors are 243/245 for GQ(3,9) but only 81/137 for GQ(9,3), so cross-GQ raw legacy fractions should not be compared without undilution.

8. New: the apartment quotient is exactly the protected H10 label space

The 10-dimensional quotient is not just numerically equal to the older CSS logical-label shadow. If C=ker(Nᵀ) is the established [40,15,8] sentinel code and C⊥=im(N), then incidence itself gives the canonical chain

C_ap/rad(C_ap) ≅ F₂⁴⁰ / ker(NᵀN) -- [b] ↦ [Nb] --> im(N) / ker(Nᵀ) = C⊥/C = H10.

The kernel and pairing are literal:

Nb ∈ ker(Nᵀ) ⇔ NᵀNb = 0 ⟨Hᵀb,Hᵀc⟩ = bᵀNᵀNc = ⟨Nb,Nc⟩.

All 2¹⁰ quotient classes were checked. This identifies the apartment-parity quotient with one protected H10 logical-label copy of the established [[40,10,4]] CSS code; the full logical Pauli label space remains 20-dimensional.

9. New: the only quadratic mismatch is the old fixed 1-layer

Both quotients carry the natural Hamming quadratic refinement q(v)=wt(v)/2 mod 2 and both have exactly 528 singular classes including zero, so both are plus-type O+(10,2). The raw incidence map is symplectic but not quadratic: the two refinements differ by one nonzero linear functional.

Nondegeneracy represents that functional by a unique isotropic class a. Under the incidence bridge its H10 image is exactly

im(Apoint mod 2) / C,

the fixed one-dimensional layer already present in the older H10=1|8|1 module filtration. A single transvection Ta(v)=v+B(v,a)a repairs the quadratic on all 1,024 classes. Because the defect line is invariant and one-dimensional over F₂, the correction is equivariant. This is a comparison-map correction, not a claim of a new physical gate.

10. New: exact orientation criterion for the bridge in GQ(s,t)

Point–line incidence always satisfies NᵀN=(s+1)I+A*. Comparing this with the general apartment Gram above and reducing modulo two gives the sharp condition

HHᵀ = NᵀN over F₂ ⇔ s ≡ 3 (mod 4) and t is odd.

So W(3,3) passes. GQ(3,9) also passes in the displayed line orientation. The dual parameter orientation GQ(9,3) fails. The bridge is therefore a characteristic-two orientation effect, not a duality invariant. This exact criterion is adjacent to—but does not explain—the empirical s/t line-signing success sweep in Pass 4457.
