## Frontier 3: renormalized boundary explicit formula

Let

```text
L(s)=-zeta'(s)/zeta(s),
a=sigma-1/2.
```

The positive Dirichlet-series cocycle is

```text
P(a,delta)
 = L(2(a-delta))-2L(2a)+L(2(a+delta)).
```

It converges only for `a-|delta|>1/2`, so it does not converge at
`sigma=1` for nonzero defect. Put `epsilon=sigma-1`. Its canonical Hadamard
finite part is

```text
FP_prime(delta)
 = lim_{epsilon->0+}[P(1/2+epsilon,delta)+1/epsilon]
 = L(1-2delta)+L(1+2delta)+2 EulerGamma.
```

Write the non-zeta part of `xi'/xi` as

```text
A(s)=1/s+1/(s-1)-(1/2)log(pi)+(1/2)psi(s/2),
```

with

```text
A(1+t)=1/t+a0+O(t),
a0=1-(1/2)log(pi)-EulerGamma/2-log(2).
```

Then

```text
FP_arch(delta)=A(1-2delta)+A(1+2delta)-2a0.
```

For `H=-xi'/xi`, the completed boundary quantity is

```text
C_xi(delta)
 = FP_prime(delta)-FP_arch(delta)
 = H(1-2delta)-2H(1)+H(1+2delta).
```

The two `1/epsilon` divergences cancel exactly; the completed difference needs
no arbitrary counterterm.

The scan over

```text

```

finds:

```text

FP_arch(delta)  < FP_prime(delta),
C_xi(delta)     > 0.
```

The completed range is

```text
8.8926583e-10 <= C_xi <= 2.1134167e-4,
```

and

```text
8.8382733e-4 <= C_xi(delta)/delta^2 <= 8.8926583e-4.
```

This is the first boundary audit to retain the prime, gamma, and endpoint
pieces together. It suggests a small positive quadratic defect after
completion. Positivity on a finite grid is not an analytic theorem for all
`delta`.
