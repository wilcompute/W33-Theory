Pass5172 — all-q incidence bridge

For any selected chamber set Y, with point and line degree vectors x,y, point-line incidence matrix N, size m, and adjacent-pair count N1, the gallery-distance-two count satisfies the exact identity

N2 = xᵀNy − (m + 2N1).

For W(3,q), NNᵀ has eigenvalues (q+1)², 2q, 0. Thus the second singular value is √(2q), producing a direct spectral upper bound on N2 from the point/line wedge split.
