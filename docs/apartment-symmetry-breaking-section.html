When does the nonsplit apartment code admit a protected section?

Full symmetry: no section

The exact sequence remains

0 → K/J (29) → E=M/J (39) → V=M/K=H10 (10) → 0.

For full PSp(4,3), the affine section equations are inconsistent:

rank(A)=389 rank([A|b])=390.

This is the Pass-4488/4490 nonsplitting obstruction.

Fix one line: the extension splits

The stabilizer of one W33 line has order 648 and index 40. Restricting the same exact equations to that subgroup gives

rank(A)=rank([A|b])=370.

Therefore line-stabilizer-equivariant sections exist. The affine family has dimension 390−370=20, and the fixed spaces satisfy dim E^H=dim V^H=3.

Fix one point: the same threshold

The point stabilizer is also order 648/index 40 and gives the identical section result:

370 = 370, affine section-family dimension = 20.

So the first tested canonical geometric gauge need not privilege the point or line side: either one-point or one-line fixation is sufficient.

Finer geometric gauges

An incident point-line flag stabilizer has order 162/index 160 and yields

rank = 338, section-family dimension = 52.

A setwise stabilizer of one building apartment has order 16/index 1620 and yields

rank = 308, section-family dimension = 82.

Less symmetry leaves more freedom in choosing a linear complement.

Architectural reading

full W33 symmetry ⇒ protected sector only as a quotient fix one point/line ⇒ equivariant 10D complement can be selected

This gives a precise gauge boundary for compiler/controller design: a globally symmetric representation should quotient out the 29-dimensional radical; a controller that deliberately fixes a point or line may instead select an equivariant representative section.

Boundary. This is a classification only for the tested canonical geometric stabilizers. It does not prove that no larger non-geometric subgroup of PSp(4,3) splits the extension. A linear section is a finite-module gauge choice, not automatically an optical decoder or hardware implementation.
