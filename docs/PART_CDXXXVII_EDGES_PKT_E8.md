# Part CDXXXVII — EDGES + PKT = E8 Roots

## The Identity

    W33_edges + Leech_dim = E8_roots
    216 + 24 = 240  ✓

The number of edges in the Schläfli graph plus the dimension of
the Leech lattice equals the number of E8 roots.

## Corollary: Triangles

    TRIS(W33) = E8_roots × p = 240 × 3 = 720 = 6!

The 720 triangles of W33 equal:
- E8 root count times the ramified prime p=3
- The factorial of the Eisenstein unit count: 6! = 720

So the triangle count of the Schläfli graph counts the **permutations
of the six Eisenstein units**, and simultaneously is **E8 roots × p**.

## The Full Chain

    EDGES(W33) = u^3 = 6^3 = 216  (six-kernel cubed)
    EDGES + PKT = E8_roots = 240
