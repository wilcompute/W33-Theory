Pass 4936: literal matrix units

Let Π48 be the rank-48 chamber projector and let Qp, Qℓ be the rank-24 point and line carriers from Pass 4334. Exact rational matrices give

e₁₁ = Qₚ, e₂₂ = Π₄₈ − Qₚ, e₂₁ = (Π₄₈ − Qₚ)QℓQₚ, e₁₂ = (64/15)QₚQℓ(Π₄₈ − Qₚ), eᵢⱼeₖℓ = δⱼₖeᵢℓ.

Thus the four-dimensional packet algebra is literally M₂(Q) on the multiplicity coordinate. The exact switch pair

Z = e₁₁ − e₂₂, S = e₁₂ + e₂₁, Z² = S² = Π₄₈, ZS = −SZ, (SZ)² = −Π₄₈

is algebraic logic on that coordinate. Its rational normalization is not an orthogonal or unitary gate construction.

The precise HoloBox checksum

The deterministic HoloBox labels HP0..HP2 and HL0..HL2 depend on a software chart. Their complete family sums do not: they recover the intrinsic point and line panel relations. Compression and affine normalization yield two exact packet reflections Hp, Hℓ with

Hₚ² = Hℓ² = Π₄₈, HₚHℓ + HℓHₚ = −(1/2)Π₄₈, 2(HₚHℓ)² + HₚHℓ + 2Π₄₈ = 0.

The aggregate turn has infinite order on the packet. This certifies whole-family consistency; it does not prove that one selected HPi or HLi preserves the packet.

Pass 4937: the ten-trit affine controller

Pass 4864 identifies the residual quotient with sp₄(F₃). Pass 4861 shows that full port matching removes the local S₃⁴⁵ sheet gauge and leaves one global PGSp(4,3) frame. Their smallest direct composition is

F₃¹⁰ ⋊ PGSp(4,3), v ↦ vA_g + w, |F₃¹⁰ ⋊ PGSp(4,3)| = 3¹⁰ · 51,840 = 3,061,100,160.

The 59,049 offsets have exactly seventeen frame-symmetry classes:

1, 80, 240, 480, 540, 540, 1080, 1080, 4320, 4320, 5184, 5184, 5760, 6480, 6480, 8640, 8640.

The equal-order firewall

The dual-number tangent extension Sp₄(F₃[ε]/ε²) and the affine PGSp controller both have order 3,061,100,160, but they are not the same group:

|Z(Sp₄(F₃[ε]/ε²))| = 2, |Z(F₃¹⁰ ⋊ PGSp(4,3))| = 1.

The square-zero kernel is elementary abelian, so its group commutator vanishes. The nonabelian Lie bracket is tangent data inherited from matrix commutators before imposing ε²=0; it is not a commutator inside that kernel.
