# V48 — Exact Lepton-Sector Closure

## Starting point

The charged-lepton packet in the prediction script is

\[
\frac{m_\mu}{m_\tau} = \frac{1}{k+q+\lambda} = \frac{1}{17},
\qquad
\frac{m_e}{m_\mu} = \frac{1}{\alpha^{-1}+v+nn+\lambda} = \frac{1}{206}.
\]

So immediately

\[
\frac{m_e}{m_\tau} = \frac{1}{17\cdot 206} = \frac{1}{3502}.
\]

## Closure packet

The sector closes exactly as

\[
\frac{m_\mu}{m_\tau} = \frac{1}{17},
\qquad
\frac{m_e}{m_\mu} = \frac{1}{206},
\qquad
\frac{m_e}{m_\tau} = \frac{1}{3502}.
\]

with

\[
17 = k+q+\lambda = 12+3+2,
\]

and

\[
206 = \alpha^{-1}+v+nn+\lambda = 137+40+27+2.
\]

So the muon denominator is a pure low-rank graph combination, while the electron denominator is an exact **fine-structure + geometry** sum.

## Geometric remainder

Subtracting the fine-structure piece gives

\[
206 - \alpha^{-1} = v+nn+\lambda = 40+27+2 = 69.
\]

Hence the electron denominator splits as

\[
206 = 137 + 69,
\]

where `137` is the electromagnetic seed and `69` is the residual W(3,3) geometric contribution.

## Multiplicative closure

The packet is multiplicatively rigid:

\[
\left(\frac{m_\mu}{m_\tau}\right)
\left(\frac{m_e}{m_\mu}\right)
= \frac{m_e}{m_\tau}
= \frac{1}{3502}.
\]

So the lepton hierarchy is not just numerically good; it forms an exact closure chain with no free scale left in the ratios.
