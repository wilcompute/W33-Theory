# Part CDXXXII — Monster Conjugacy Classes and W33

## 194 Classes

The Monster group M has 194 conjugacy classes. In W33 terms:

    194 = FLAGS_T + 2 = |W(D4)| + 2 = 192 + 2  ✓
    194 = 8·PKT + 2  ✓
    194 = 2·(4·PKT + 1) = 2·97  ✓

where 97 = 4·PKT + 1 is prime.

## McKay-Thompson Series

For each of the 194 conjugacy classes, Conway-Norton proved the
McKay-Thompson series T_g(τ) is a Hauptmodul for a genus-0 subgroup.
The number of distinct genus-0 groups needed = 15 = K-1.

The j-function itself (class 1A) has:

    j(τ) = q⁻¹ + 744 + 196884q + ...
