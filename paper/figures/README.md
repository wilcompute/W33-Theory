# paper/figures — Figure Generation Scripts

All figures are generated by running the scripts in this directory.
Outputs are written as both `.pdf` (for LaTeX inclusion) and `.png` (for preview).

## Requirements

```
pip install numpy matplotlib scipy
```

## Scripts

| Script | Output | Description |
|--------|--------|-------------|
| `fig1_mu_eff_scan.py` | `fig1_mu_eff_scan.{pdf,png}` | μ²_eff vs Σmν scan over NH/IH orderings with W(3,3) fixed-point lines and DESI DR1 UL verticals |
| `fig2_rg_distance.py` | `fig2_rg_distance.{pdf,png}` | RG distance \|δ\|² bar chart for all SM sectors vs nearest W(3,3) fixed point |
| `fig3_seesaw_cascade.py` | `fig3_seesaw_cascade.{pdf,png}` | Seesaw cascade ladder T⁰→T³ with W(3,3) rungs and spectral RG descent plot |

## Running all figures

From the repo root:
```bash
python paper/figures/fig1_mu_eff_scan.py
python paper/figures/fig2_rg_distance.py
python paper/figures/fig3_seesaw_cascade.py
```

Or use the Makefile target (once added):
```bash
make figures
```

## Citation

All scripts use NuFIT 5.3, PDG 2024, and DESI DR1 values as hardcoded
constants. Update the constants at the top of each script if newer data
becomes available.
