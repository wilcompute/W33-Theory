\begin{abstract}
This revision strengthens the W33 holographic-code paper by separating the internal graph $W(3,3)$ from the horizon graph $K_{12}$ and by adding the new minimal-logical surface invariants.  The internal graph is the generalized-quadrangle collinearity graph with $40$ vertices and $240$ edges; the horizon graph is $K_{12}$, whose orientable complete-graph genus is
\[
        g(K_{12})={(12-3)(12-4)\over 12}=6.
\]
The tower is organized by $(q,g,h)=(3,6,12)$ and contains the bulk qutrit CSS code $[[240,81,3]]_3$ and the horizon code $[72,66,3]_3$.  The main new result is that the canonical W33 edge CSS code has minimal logical rays
\[
        |\Xmin|=160,\qquad |\Zmin|=1620,
\]
with vector counts $320$ and $3240$.  The nonzero vector-level $X/Z$ commutation census is
\[
        25920+25920=51840=|\Weyl(E_6)|.
\]
Retaining phase gives a signed matrix $A\in\{-1,0,1\}^{160\times1620}$ satisfying
\[
        \Spec(AA^T)=160^{81}\oplus0^{79},
\]
so $AA^T/160$ is an exact rank-$81$ projector.  Thus the unsigned minimal-logical shadow is the Weyl order of $E_6$, while the signed phase geometry is the protected $81$-dimensional homology sector.
\end{abstract}

\section{What changed in this revision}

The previous draft assembled the code-tower numerology, but it blurred three objects that should be kept distinct:
\begin{enumerate}[label=(\roman*)]
\item the internal $W(3,3)$ graph, whose $240$ edges are the bulk physical qutrits;

\section{Riemann--Roch dimension layer}

\begin{proposition}[Dimension rule]
For a genus-$6$ evaluation code $C_{\mathcal L}(D,G)$ with $\deg(G)=n-1>2g-2$ and $\ell(K-G)=0$,
\[
        k=\ell(G)=\deg(G)-g+1=n-g.
\]
Hence $n-k=g=6$.
\end{proposition}

\begin{proof}
Riemann--Roch gives $\ell(G)-\ell(K-G)=\deg(G)-g+1$.  Since $\deg(G)>2g-2$, the correction term vanishes.  Substituting $g=6$ and $\deg(G)=n-1$ gives $k=n-6$.
\end{proof}

\section{Signed rank-$81$ phase frame}

Define the signed projective phase matrix
\[

+1,&\langle x,z\rangle=1,\\
-1,&\langle x,z\rangle=2=-1.

Then $A\in\{-1,0,+1\}^{160\times1620}$.

\begin{theorem}[Phase-frame theorem]
\[

Consequently
\[
        \rankop(A)=81,
        \qquad
        \left({1\over160}AA^T\right)^2={1\over160}AA^T.

\end{theorem}
