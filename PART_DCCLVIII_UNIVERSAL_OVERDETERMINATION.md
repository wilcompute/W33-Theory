## 5. Why this level of overdetermination matters

In any other physical theory, the foundational parameter (mass, charge,
coupling) is *fitted* from one or a few experiments. The W(3,3)
program's foundational parameter q = 3 is **algebraically forced** by
15 independent conditions, each of which is a classical theorem
predating the W(3,3) program:

* Kissing-number theorem (Newton 1694; Schütte–van der Waerden 1953)
* Frobenius / GQ theory (Tits 1957)
* Pascal / Mersenne theorems (Euler, Pascal, Mersenne)
* Monster classification (Conway-Norton-Borcherds 1979-1992)
* E_6 / Schläfli / GQ uniqueness (classical 19th century)
* Sphere-packing densities (Thue 1890, Hales 1998, Viazovska 2016/2017)
* Loop-closure / Euler characteristic (Euler)
* Weinberg-angle sin²θ_W algebraic root (paper)

All of them, at integer q, return q = 3 alone. No fitting. No tuning.

  arises in 11+ independent mathematical universes** — an arithmetic
