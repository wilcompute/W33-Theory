The Deficit Law

          
For the 120-sheet Holonet, the max-satisfiable score is 36/40. The 4-line deficit is exactly one point-star (q+1 contexts).

        

        

          
Movable Point-Star

          
The deficit is not an error; it is a gauge freedom. The scheduler can steer the 4-line "tax" to any point in the fabric.

        

      

      
The price of the machine's quantum advantage (in the 540-cover) and its mandatory scheduling overhead are the same exact integer: CF = 1/(q²+1) = 1/10.

    


    

      
Physical Falsifier

      
One photon can kill or advance the program.

      

        

          
Uniqueness

          
W(q) requires C^(q+1). Numerical search at q=4 fails (error ~18), while correctly finding the Witting q=3 realization. q=3 is the unique minimal substrate.

        

        

          
Control arm

          
The newest discriminator runs the same estimators on W(3) and even-q controls. The investor question becomes separation, not belief.

Computer Engineering

      
The node is tiny because the geometry is the operating system.

      

        

          
Minimal VM

          
A node needs ternary arithmetic: add, subtract, multiply mod 3. The rest is generated by the address
            geometry.

        

        

          
Retro firmware

          
The router has been compiled into small 4-bit and 8-bit-style traces. This is a serious embedded
            architecture, not just a cloud simulator.

        

        

          
Zero table

          
Pass 53 measures the table-free win: 1170 bytes -> 0 for the q=3 all-pairs routing state when
            address is route.
