# BT1577 Radial Leakage Bound from OAM Phase Operations

A symbolic row-stochastic leakage matrix is assigned to each internal operation across radial shells p=0,1,2.

I has zero leakage. Z, S, X, and F3 receive increasing envelopes up to the default 0.10 threshold.

This is an engineering bound, not measured optical leakage.
