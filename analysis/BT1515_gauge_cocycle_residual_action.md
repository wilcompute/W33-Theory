# BT1515 Gauge-Cocycle Residual Action

Residual keys transform by `rho -> R^{-1} rho L` for right and left line gauges.

The finite S3 key-space action is closed, has identity and inverse laws, and composes associatively.

This is the algebraic cocycle law. The full decorated Aut(W33) orbit test still needs transported gauge labels for each automorphism generator.
