% PASS20260906 -- three-copy exact stabilizer witnesses (symmetric-family exhaustion)
\section*{Current magic frontier: symmetric acceptance witnesses have no logical output}
\addcontentsline{toc}{section}{Current magic frontier: symmetric acceptance witnesses have no logical output}

\noindent\textbf{Scope.}
An exact finite search result about an acceptance condition: annihilate the
single-error subspace and accept the clean input with nonzero probability.
The resulting output need not be the clean magic ray. Here every returned hit
has a one-dimensional stabilizer range, so these branches have no logical
output and cannot supply a distilled magic state through stabilizer decoding.

\paragraph{The search that was asked for.}
Pass 2861 exhausted all $5{,}355$ two-copy $[[4,2]]$ codes: zero super-linear branches.
Pass 2881 sampled $30{,}000$ random six-qubit stabilizer groups at three copies: zero;
Pass 4680 then proved that sample had at most about one percent power unless witnesses
number in the tens of thousands.  The recorded ask was an \emph{exhaustive search over
a chosen code family}.  The chosen family is canonical: the exact condition is
copy-permutation invariant, so the search exhausts ALL $S_3$-invariant stabilizer
groups.  By the isotypic decomposition $\FF_2^{12}=\FF_2^4\otimes(\mathrm{triv}\oplus
\mathrm{std})$, every such group is $V_t\oplus W_T$ with $V_t,T$ isotropic in the
$2$-qubit label space ($31$ choices each, automatically mutually orthogonal), giving
exactly
\[
961 \text{ groups},\qquad 27{,}391 \text{ signed syndrome projectors per ray}.
\]

\paragraph{The result.}
Exact integer arithmetic in $\ZZ[\zeta_{12}]$ (Walsh--Hadamard over each group's
$2^r$ sign assignments, with the full Pauli operator-product phase cocycle ---
dropping it was two false starts) against
\[
\operatorname{Tr}(PJ)=0
\quad\text{and}\quad
\langle mmm|P|mmm\rangle\neq 0 ,
\]
finds, for the $36$ $\mathrm{M}_{36}$ rays:
\[
\boxed{\text{104 witnesses, every reported one independently re-verified by a dense
projector construction on a separate code path.}}
\]
Per family: seven rays carry $2$ witnesses and two rays carry $6$. All witnesses
have generator rank $6$ and projector rank $1$. A representative for ray
$\mathrm{A}_{00}=(0,1,-1,1)/\sqrt3$:
the group generated by
\[
X_2^{\otimes 3},\quad X_1^{\otimes 3},\quad
Z_2^{(13)},\quad Z_2^{(23)},\quad Z_1^{(13)},\quad Z_1^{(23)},
\]
with generator signs $(-,+,+,+,+,+)$, annihilates all nine single-error inputs and
accepts the clean input with nonzero probability.

\paragraph{Connection to the existing obstruction.}
These are acceptance witnesses, not generators stabilizing the clean input.
Passes 2933 and 2977 already found rank-one acceptance witnesses and identified
their lack of magic output; Pass 2990 and the blueprint's three-copy section
record that obstruction. The symmetric-family enumeration adds coverage and
counts, not the first existence proof or a useful distillation protocol.

\paragraph{What changes.}
The acceptance predicate is satisfiable, as was already known. An independent
output-rank audit replays the enumeration, checks commutation and binary rank,
and dense-checks every returned witness. All $104$ hits have six independent
generators on six qubits: $k=6-6=0$ and projector rank $2^k=1$.
There is no remaining logical output for a stabilizer decoder to turn into
magic. Useful super-linear distillation remains open; this result does not
exclude asymmetric protocols or protocols with a different correction condition.
