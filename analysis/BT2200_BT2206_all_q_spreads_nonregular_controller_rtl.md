## 2201 — the regular-spread formulas are an all-odd-q theorem

Use the parabolic quadric `Q=Q(4,q)` with odd `q`.  A regular symplectic spread is the elliptic hyperplane section

`O_x = Q ∩ x^perp`

for a minus-type anisotropic projective point `x`.  Hence the vertex count is

`v = q^2(q^2-1)/2`.

For two vertices define the projective Gram determinant

`Delta(x,y)=4Q(x)Q(y)-B(x,y)^2`.

The intersection plane `x^perp ∩ y^perp` is tangent to `O_x` exactly when `Delta=0`; otherwise it is secant.  Therefore two distinct regular spreads meet in exactly

`1` or `q+1`

lines for every odd `q`.

Let `M` be incidence between elliptic sections and singular points of `Q(4,q)`.  Each section has `q^2+1` points; a singular point lies in `q^2(q-1)/2` elliptic sections; a noncollinear singular pair lies in `q(q-1)/2`; a collinear pair lies in none.  Thus

`M^T M = d I + b(J-I-A_Q)`

and, on the section side,

`M M^T = q^2 I + J + q A`,

where `A` joins the `q+1` intersections.  The standard spectrum of the point graph of `Q(4,q)` now gives

`A = SRG(v,k,lambda,mu)`

with

- `k = q(q-2)(q^2+1)/2`,
- `lambda = q(q^3-4q^2+7q-8)/2`,
- `mu = q(q-2)(q-1)^2/2`,
- nontrivial eigenvalues `q(q-2)` and `-q`,
- multiplicities `q(q^2+1)/2` and `(q-2)(q+1)(q^2+1)/2`.

This closes the conjectural part of Pass 2064.  The correct general language is a two-class strongly regular fusion; for `q>3` the full group action need not itself have rank three.

The executable orthogonal model verifies `q=3,5,7,11`; at `q=11` it constructs 7,260 minus points and checks `(k,lambda,mu)=(6039,5038,4950)`.

## 2204 — the actual single-J controller has order 24

The abstract independent-clock model

`Gamma=(C4 x C6):C2`

has order 48.  On the canonical `90`, however, both clocks rotate the same complex structure `J`.  The literal map is

`(a,b,e) -> (3a+2b mod 12,e)`

into `C12:C2`.  It is surjective with kernel

`{(0,0,0),(2,3,0)}`.

Hence the actual canonical image is

`D24 = C12:C2`, order 24.

The abstract `D8` and `D12` share only the inverter, but their represented images intersect in a Klein four.  A faithful order-48 implementation therefore requires two independent complex phase registers; `End_PSp(90)=C` supplies only one.
