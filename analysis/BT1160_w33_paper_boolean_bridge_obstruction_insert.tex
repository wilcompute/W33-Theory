\begin{remark}[Boolean bridge: spanning yes, equivariance open]
\label{rem:boolean-bridge-obstruction}
The refined Boolean/Clifford bridge now has an explicit $40\times15$ feature
matrix $F$ such that
\[
  \operatorname{rank}(P_-F)=15.
\]
Thus the projected Boolean features span the $W(3,3)$ negative eigenspace.
However, the present feature choice is not yet a column-level equivariant mask
module: the selected offsets depend on the mask, so coordinate permutations
preserve the grade ledger $4+6+4+1$ but do not strictly permute the chosen
columns.  Therefore the paper records a spanning bridge and an equivariance
obstruction, not an equivariant-module theorem.  The next target is an invariantly
generated feature family whose projection still has rank $15$.
\end{remark}
