### 1. Full E8 grading: an exact 81-truncation leakage obstruction

Using the validated actual Pass11681 E8 `sl9+Λ³(9)+Λ³(9)*`
structure constants, remove three disjoint trivector basis elements:
`012, 345, 678` from each 84-dimensional charged grade, leaving
two tempting 81-dimensional subspaces.

**Exact result:** Every one of the original **84** dual-trivector
channels occurs as a nonzero bracket of two retained 81-grade basis
elements. In particular the three excluded outputs are unavoidably
generated by concrete allowed triples:

| Lost output | Allowed first | Allowed second | Exact coefficient |
|---|---|---|---:|
| 012 | 346 | 578 | -1 |
| 345 | 016 | 278 | +1 |
| 678 | 013 | 245 | -1 |

The producer validates these using the existing `wedge_star`
Lie-bracket routine: `[81,81]` is **not closed** under this simple
coordinate truncation. On the mixed grade, retained triples sharing
two basis directions generate **all 72** independent matrix
off-diagonals; the 81 matching-triple diagonal weight vectors have
rank nine, hence span the **eight** traceless diagonal directions.
So the old sl9 grade-zero sector is fully generated (80D), not the
86D E6+A2 grade-zero sector.

**Boundary:** This is an exact falsification of a particularly plausible
shortcut; it DOES NOT rule out the real standard E8
`(78,1)+(1,8)+(27,3)+(27*,3*)` grading. Building an
intertwining change of grading and proving PGSp-equivariance for the
actual Steinberg-81 matter sector is still unresolved. Dimension
`81=27×3` and existence of one invariant cubic do not supply those maps.

### 2. Real three-boson native W33 quantum vacuum, not just mean field

Implemented the entire `N=3` Hilbert sector of the attractive
W33 80-site Bose-Hubbard model:
`C(82,3)=88,560` Fock states, **1,036,800** sparse hopping entries.
Full Lanczos eigensolutions, `t=1`, returned:

| U/t | Ground energy | Gap | 3-on-one-site probability |
|---:|---:|---:|---:|
| 0 | -12.000000 | 1.550510 | 0.00015625 |
| 4 | -13.925778 | 0.136620 | 0.713936 |
| 8 | -24.851292 | 0.035684 | 0.940817 |

For every U tested, each of the 80 vertices has occupation
`<n_i>=3/80` up to numerical Lanczos solver tolerance (the independent
runs range from approximately 1e-12 to 1e-7 absolute error).
The **exact, any-finite-N** proof uses irreducibility of hopping on
bosonic Fock states, stoquastic nonzero off-diagonal matrix elements
and Perron–Frobenius: for finite N and t>0 the ground state is
unique, positive and invariant under graph automorphisms.

The physical attraction makes multimers but cannot spontaneously
select a site at any finite N. A finite-density thermodynamic limit
(`N/|V|` fixed while |V| grows), symmetry-breaking pinning field,
or explicit coupling to an environment is required.

### 3. Actual dynamics on the 1,620 W33 symplectic frames

Take the **previously known 1,620 C4 apartments** as the quantum
basis. Build two *different but exactly full-PSp-invariant*
sparse hopping relations:

- `A3`: frames sharing exactly **three** of four projective rays.
  It is **8-regular and has 45 connected components of size 36**.
  Each connected 36-frame sector has adjacency eigen-spectrum
  `8^1,4^6,2^4,0^9,(-2)^12,(-4)^4`, gap 4, and 96 triangles.
  For `H=-t A3`, the ground-energy level is exactly
  **45-fold degenerate**, uniform on each component.
- `A2`: frames sharing exactly **two** rays (but not three).
  It is **90-regular and connected**.
  Add `-eps A2`, eps>0. Because both relations are invariant
  and their sum is connected, **Perron–Frobenius restores a unique
  global symmetry-invariant ground state for any eps>0**.

Measured dimensionless lifting of the frame-level gap in
`H=-(A3+eps A2)`: eps=.01 -> 0.658969;
eps=.1 -> 5.645668; eps=1 -> 47.23858. An additional
localized selector `-h |apartment0><apartment0|`
selects one of the otherwise 45-degenerate components and raises
its particular-frame probability from a near-uniform 1/36 value
to about 0.648 at h=8.

**Consequently the 45×36 sector decomposition is dynamical and
unprotected**, because a different *also invariant* hopping rule
destroys it.

Each selected symplectic apartment carries four projective coordinate
axes. For q=3 it yields a local C3^4 torus (81 sites),
but no broad constant-four spectral dimension. Merely *postulating*
an enlarged Cartesian four-torus C_m^4 gives, at t=16:
`d_s(m=3)=0.0000000145`,
`d_s(m=9)=1.35427`,
`d_s(m=27)=4.06685`, and
`d_s(m=81)=4.06685`.
This demonstrates a conditional **Euclidean** 4D heat window
only after an additional externally chosen refinement, NOT
emergent 3+1D Lorentzian gravity or a derived light cone.

### 4. Selective Wilson flatness restores logical qutrits

Use the same exact 160-link qutrit Gauss constraints (rank 79),
and impose **selected** native 8-cycle Wilson stabilizers.
Exact row ranks are over F3. We enumerated *all 160 possible
distinguished incidence edges* and found for every edge:
**81 through-edge apartments, rank 81**; and the complement
**1539 away-from-edge apartments, rank 80**.

Through-edge basis is *already BT744*, independently reproduced.
The **complementary rank**, plus the resulting qutrit stabilizer
logical counts, is the newly evaluated dynamical question.

| Wilson subset | Cycles included | rank r | Logical qutrits 81−r |
|---|---:|---:|---:|
| all eight-cycles | 1620 | 81 | 0 |
| through one selected edge | 81 | 81 | 0 |
| avoiding selected edge | 1539 | 80 | **1** |
| through selected point | 162 | 81 | 0 |
| avoiding selected point | 1458 | 78 | **3** |
| through point AND nonincident line | 9 | 9 | **72** |

The native commuting Pauli Hamiltonian for each selector is
`H=-g Σ_vertices(G_v+G†_v)-k Σ_selected_cycles(W_c+W†_c)`.
Each eigenconstraint commutes because the Wilson row is a closed cycle
orthogonal to every vertex incidence row. Exact stabilizer rank
`79+r` yields code dimension `3^(81-r)`.

This shows several concrete finite models retaining one, three,
or 72 logical qutrits despite partial flatness. It does NOT yet show
code distance, fault tolerance, matter coupling, topological order,
or a 3+1D physical lattice. The exceptional vertex/edge is supplied,
rather than dynamically derived.

### 5. A genuine scale-free simulator signature, not a particle-mass claim

For the native W33 N=2 Bose-Hubbard `H=-t hopping-U doublon`,
project onto the 80 on-site pair states and compute **exactly** the
second-order degenerate Schrieffer–Wolff matrix:

`K=P H_hop (1-P) H_hop P = 8 I_80 + 2 A_Levi`.

Since the native Levi adjacency eigenvalues are
`4^1, (sqrt6)^24, 0^30,(-sqrt6)^24,(-4)^1`,
the leading strong-coupling doublon excitations have a
**parameter-free set of dimensionless gap ratios** relative
to the first excitation:

`1, 4/(4-sqrt6), (4+sqrt6)/(4-sqrt6), 8/(4-sqrt6)`.

These are exactly computable irrational algebraic numbers
and a falsifiable **model-specific** quantum-simulator
signature if the native graph and strong attraction are physically
implemented.

The low-band first gap is
`Δ=(2t²/U)(4-sqrt6)+O(t⁴/U³)`.
Direct **full 3240D exact finite Hamiltonian numerical** comparisons
give relative errors:
U/t=16: -0.03790,
32: -0.01008,
64: -0.002545,
128: -0.0006374.
This matches the expected suppression of neglected higher orders.

**Crucial boundary:** This is parameter-independent *conditioned on
the externally assumed attractive Bose-Hubbard Hamiltonian and
large-U/t limit*. It is not a prediction of actual electron/quark
masses, gauge couplings or gravitational constants. No absolute scale
is supplied by finite W33 incidence geometry alone.
