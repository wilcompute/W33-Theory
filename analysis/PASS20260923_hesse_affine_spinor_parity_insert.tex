\subsection*{The complete Hesse affine group carries the spinor-parity bit}

The determinant/spinor-norm identity extends over the translation layer.
For an affine symmetry
\[
 x\longmapsto gx+t,\qquad t\in\mathbf F_3^2,\quad g\in GL(2,3),
\]
define
\[
 \boxed{
 \chi(t,g)=\det(g)=\theta_{\rm spin}(\rho(g)).
 }
\]
Exhaustion of all \(432^2=186624\) ordered products proves that \(\chi\)
is a surjective homomorphism
\[
 AGL(2,3)\longrightarrow C_2
\]
with
\[
 \boxed{
 \ker\chi
 =
 \mathbf F_3^2:SL(2,3)
 =
 ASL(2,3),
 \qquad |\ker\chi|=216.
 }
\]
Hence the projective one-qutrit Clifford/Hessian group is exactly the trivial
spinor-parity half of the full Hesse affine group, while the other \(216\)
elements form the determinant-minus-one/anti-linear coset. The nine
translations lie in the kernel.

Under the orthogonal lift, the \(432\) affine elements map in fibers of size
\(18=9\cdot2\) onto \(SO(Q)\): nine translations times the central pair
\(\{\pm I_2\}\). Thus
\[
 \boxed{
 \chi=\det_{\mathbf F_3^2}=\text{spinor norm on }SO(Q)
 }
\]
after pullback.
