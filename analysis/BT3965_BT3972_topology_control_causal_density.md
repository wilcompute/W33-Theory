## 3970 — photon causal density

The user's intuition survives most strongly as a shared causal-action budget, not as a node-count-dependent vacuum light speed.

If serial node spacing is ell and local tick duration is tau,

\[
v_{\rm front}=\ell/\tau.
\]

Lorentz-compatible vacuum propagation requires ell/tau=c. Packing N serial nodes into length L therefore demands

\[
\ell=L/N,\qquad\tau=L/(Nc).
\]

The Margolus–Levitin limit bounds orthogonal state changes by 2E/(pi hbar). For a photon E=h nu, this is 4 nu. During flight time L/c,

\[
\boxed{N_{\rm serial}\le4EL/(hc)=4L/\lambda}.
\]

At 1550 nm, ideal serial depths 2, 12, 39, 40, and 81 require minimum lengths 0.775, 4.65, 15.1125, 15.5, and 31.3875 micrometers. Forty literal serial updates within one wavelength would require a 40 nu update clock while the bound permits 4 nu: a factor-ten contradiction.

Parallel orthogonal modes are different. They enlarge the alphabet without representing the same number of sequential state transitions. A finite M-mode one-photon alphabet carries log2(M) ideal bits: 5.321928 bits for 40 modes and 9.509775 bits for 729 modes.

This separates three resources:

- propagation: invariant causal front c;
- processing: energy-limited orthogonal-state update rate;
- memory/capacity: the available distinguishable mode space.

The identity f=1/T does not force information amount and efficiency to be inverses. Throughput is R=I/T=If, and I and f are separately constrained by bandwidth, energy, noise, and causality.

A literal hidden-node dependence of vacuum c has a sharp falsifier: changing mode count, encoding, or photon frequency must cause a front-arrival delay or Lorentz-violating vacuum dispersion. The model therefore preserves invariant c and treats any variable-c ontology as unsupported unless that prediction is observed.
