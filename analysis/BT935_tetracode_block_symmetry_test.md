# BT935 — Tetracode A2^4 block symmetry test

BT932 showed that the BT926 vertex E8 witness is symmetry-isolated. BT935 therefore tests the first nontrivial symmetry target left: the W33 tetracode/A2^4 block structure.

## Tetracode symmetry

For the standard ternary tetracode generated by

```text
[0,1,1,1], [1,0,1,2]
```

BT935 finds:

- code size: 9;
- coordinate-permutation symmetries: 3;
- signed monomial symmetries: 48.

The coordinate permutations are:

```text
[0,1,2,3]
[0,2,3,1]
[0,3,1,2]
```

## Reading

Unlike the isolated vertex witness, the tetracode glue has a nontrivial signed monomial symmetry group of order 48. This makes the tetracode A2^4 structure the correct next target for equivariant chain-to-E8 selection.

## Boundary

This pass identifies the symmetry target; it does not yet construct a compatible chain action or prove equivariant uniqueness.
