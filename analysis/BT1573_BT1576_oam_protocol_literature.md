# BT1573-BT1576 OAM Protocol and Literature Packet

## BT1573

The translated Clifford elements split into eight nonzero shift classes. Each class has 24 frame choices. The correction is the inverse shift, with OAM-only, phase-only, and mixed classes.

## BT1574

S and F3 are calibrated on the same centered OAM basis. S has phase signature [1,0,1], and F3 is the finite three-mode mixer on the same qutrit labels.

## BT1575

The protocol table is paper-ready. It covers preparation, passive controls, active gates, leakage, covariance, reference comparison, expected readouts, thresholds, failure modes, and claim tiers.

## BT1576

Current OAM literature supports qudit and same-photon register directions, but also warns that radial and azimuthal structure must be treated together. The witness burden therefore includes radial leakage and mode-overlap tests.
