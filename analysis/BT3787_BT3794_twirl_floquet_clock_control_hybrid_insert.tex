\paragraph{Floquet cancellation.}

\[
\frac1{40}\sum_{t=0}^{39}C^{-t}DC^t

\]
Hence all traceless static diagonal disorder cancels exactly over one orbit.  This is not a general coherent-error or loss theorem.
