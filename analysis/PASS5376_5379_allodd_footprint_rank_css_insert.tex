\subsection{The all-odd binary footprint theorem is closed}
\label{sec:pass5376-footprint-rank-closed}

Let $C_W\subseteq\mathbb F_2^{\mathcal P}$ be the binary code spanned by the
lines of $W(3,q)$ on the point set $\mathcal P$, and let $F$ be the
point-versus-$P$-component footprint matrix whose columns are the indicators of
polar pairs $H\cup H^\perp$ of non-isotropic projective lines.  Passes
5201 and 5288 already give
\[
 \operatorname{im}_2F\subseteq C_W^\perp,
\]
because every footprint block meets every $W$-line in zero or two points.
Moreover, every point belongs to exactly $q^2$ footprint blocks, so for odd $q$
the sum of all columns of $F$ is the all-one vector $\mathbf 1$.  Since a
single footprint column has weight $2(q+1)<|\mathcal P|$, we have the strict
containment
\[
 \langle\mathbf1\rangle<\operatorname{im}_2F\le C_W^\perp.
\]

The missing step is supplied by the complete characteristic-two point-module
lattice of Lataille--Sin--Tiep.  Their incidence map $\eta_{2,1}$ is exactly
the line-to-point incidence map of $W(3,q)$, so their code
$C=\operatorname{im}\eta_{2,1}$ is $C_W$.  They prove
$C^\perp=U'$ and, because $m=2$ is even, the bottom interval is uniserial:
\[
 \boxed{U'>\langle\mathbf1\rangle>0.}
\]
Their field-of-definition remark carries this submodule interval to
$\mathbb F_2$.  Hence $C_W^\perp/\langle\mathbf1\rangle$ is simple.  The strict
submodule sandwich above therefore forces
\[
 \boxed{\operatorname{im}_2F=C_W^\perp.}
\]
Using
\[
 \dim C_W=1+\frac{q(q+1)^2}{2}
\]
then gives, for every odd prime power $q$,
\[
 \boxed{
 \operatorname{rank}_2F=\frac{q(q^2+1)}2,
 \qquad
 \ker_2(F^T)=C_W.
 }
\]
This is the formerly open all-odd footprint-rank theorem, not a finite-anchor
extrapolation.

\subsection{Rank complement and zero-footprint generation}
\label{sec:pass5377-rank-complement-closed}

Write
\[
 f=\frac{q(q+1)^2}{2},
 \qquad
 g=\frac{q(q^2+1)}2.
\]
Together with the characteristic-zero frame theorem of Pass~5267, the complete
rank complement is now exact:
\[
 \boxed{
 \operatorname{rank}_{\mathbb Q}F=1+f=\operatorname{null}_{2}F,
 \qquad
 \operatorname{null}_{\mathbb Q}F=g=\operatorname{rank}_{2}F.
 }
\]
Pass~5299 had already constructed the same-point difference code $D_q$ and
proved
\[
 D_q\subseteq K_0,
 \qquad
 \dim D_q=q^4-g,
 \qquad
 \dim K_0=q^4-\operatorname{rank}_2F.
\]
Therefore Pass~5376 closes the last dimension gap and yields
\[
 \boxed{K_0=D_q}
\]
for every odd prime power $q$.  Thus the three formerly equivalent conjectures
\[
 \operatorname{rank}_2F=g,
 \qquad
 \ker_2(F^T)=C_W,
 \qquad
 K_0=D_q
\]
are now three equivalent theorems.

\subsection{The footprint image is generated by its complete minimum shell}
\label{sec:pass5378-minimum-shell-spans}

Pass~5189 already proved, for every prime power $q$, that
$C_W^\perp$ has minimum distance
\[
 d(C_W^\perp)=2(q+1),
\]
and that its complete minimum shell consists exactly of the dual grids
\[
 H\cup H^\perp,
\]
one for each polar pair of non-isotropic projective lines.  There are
\[
 \frac{q^2(q^2+1)}2
\]
such words.  These are exactly the columns of $F$.  The new equality
$\operatorname{im}_2F=C_W^\perp$ therefore upgrades the old minimum-shell
classification to the all-odd spanning theorem
\[
 \boxed{
 C_W^\perp
 =\left\langle\,H\cup H^\perp:\ H\text{ non-isotropic}\,\right\rangle_{\mathbb F_2}.
 }
\]
Equivalently the footprint image is the classical binary code
\[
 \boxed{
 \left[(q+1)(q^2+1),\ \frac{q(q^2+1)}2,\ 2(q+1)\right]_2
 }
\]
generated by a single $\PSp_4(q)$-orbit consisting of \emph{all} of its
minimum words.

\subsection{Binary point-code CSS corollary}
\label{sec:pass5379-binary-css-family}

The same Lataille--Sin--Tiep lattice gives
\[
 C_W^\perp\subset C_W.
\]
Hence the footprint code $C_F=C_W^\perp$ is self-orthogonal and may be used as
both the $X$- and $Z$-check space of a binary CSS stabilizer code.  The length
and check rank are
\[
 n=(q+1)(q^2+1),
 \qquad
 \operatorname{rank}H_X=\operatorname{rank}H_Z=g,
\]
so
\[
 k=n-2g=q^2+1.
\]
For regular generalized quadrangles the binary line code $C_W$ has minimum
weight $q+1$, attained by line incidence vectors.  A $W$-line does not lie in
$C_W^\perp$: any intersecting $W$-line has inner product one with it.  Therefore
both logical distances are exactly $q+1$, and we obtain the all-odd family
\[
 \boxed{
 \left[\!\left[(q+1)(q^2+1),\ q^2+1,\ q+1\right]\!\right]_2.
 }
\]
The first examples are
\[
 [[40,10,4]]_2,\qquad
 [[156,26,6]]_2,\qquad
 [[400,50,8]]_2,\qquad
 [[820,82,10]]_2.
\]
This is a binary \emph{point-code} CSS family.  It is distinct from the
project's ternary edge code $[[240,81,3]]_3$; no equivalence between the two is
claimed.

\paragraph{Evidence boundary.}
Passes~5376--5379 close the all-odd binary footprint rank, kernel, same-point
$K_0$ generation, complete minimum-shell spanning, and the abstract CSS
parameters above.  They do \emph{not} close the $q=11$ dual weight-$20$
existence/$d=121$ problem, the Hoffman shortened-code distance
$d\in\{28,32,36,40\}$, any fault-tolerant threshold, or a hardware realization
of the binary CSS family.
