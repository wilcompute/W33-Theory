## Why this file exists

that already exists elsewhere, uncited**, and `[[240,81,3]]` is the single largest
cluster:

```text

```

That is not 51 independent derivations. It is one result quoted 51 times, and the
cost is that a reader cannot tell which file to believe, which is load-bearing, or
whether the distance was ever re-derived or only copied forward.

**If you are asserting `[[240,81,3]]`, cite this file or the owner directly.** That
is the whole ask, and it is also exactly what silences the guard warning.
