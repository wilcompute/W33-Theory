# BT1600 Full Witting Transaction Cycle

BT1600 compiles every Witting ordered pair into one `72`-tick frame:

```text
40 source rays * 40 target rays = 1600 frames
1600 * 72 = 115200 ticks
520 accepted control frames + 1080 contextual fuel frames
```

The `120` same-ray phase-sheet records from BT1599 are a selector sidecar, not extra cycle frames.
