# BT1601 Single-Photon Transaction Automaton

BT1601 compiles the full BT1600 ordered-pair cycle into one physical single-photon automaton.  The automaton has `1600` states, `115200` ticks, `520` Witting analyzer switch frames, and `1080` OAM/Hesse fuel switch frames.  Every state includes an explicit switch bank, delay placeholder, detector handoff, symbolic loss channel, and dark-reference placeholder.
