\subsection{The 66-qutrit store and the K12 correction}

eight cyclic $[[5,1,3]]_3$ blocks plus $26$ frozen single-site $Z$ ancillas.
The new bridge derives a symplectic logical pair for the five-qutrit block and
maps the seven logical qutrits of the $[[20,7,2]]_3$ source into seven independent
logical blocks of this distance-three store.  This is a logical
 decode/code-switch/re-encode bridge, not a monomial embedding of twenty
physical qutrits into sixty-six.  After a successful recode the stored state has
distance three; source-side operations before that recode remain distance two.

The same calculation exposes an important correction to older architecture
prose.  The committed orientable $K_{12}$ completion has
\[
 V=12,\qquad E=66,\qquad F=44,\qquad g=6.
\]

\[
 \operatorname{rank}\partial_1=11,\qquad
 \operatorname{rank}\partial_2=43,
\]
and therefore the standard closed orientable edge surface code has
\[
 k=66-11-43=12=2g,
\]
not $8$.  Thus the phrases ``the 66-edge $K_{12}$ compiler surface'' and
``the explicit $[[66,8,3]]_3$ protected store'' must not be identified with the
standard homological $K_{12}$ surface code.  A $K_{12}$-native $k=8$ claim would
need four additional independent commuting stabilizer/gauge-fixing constraints
specified explicitly.
