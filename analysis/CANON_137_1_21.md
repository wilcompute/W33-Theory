## The correction

`PASS358_359_GITHUB_BATCH_INTEGRITY_ALPHA_CODE_SYNTHESIS.md` refuted and upgraded it:

> **`[[137,1,21]]`** — the binary cyclic CSS code from the quadratic-residue

Its own retraction table names the superseded passes:

| claim | verdict |
|---|---|
| Passes 77/91, weight-three Alpha word | **refuted and upgraded**; exact CSS code is `[[137,1,21]]` |

This is also the code whose unsupported `[[137,1,3]]` form arrived in the July 15
remote batch and had to be refuted by GAP *after* commit — the episode that motivated
the batch-intake protocol in `CLAUDE.md`. Quoting the old value re-imports the very
error that protocol exists to stop.

## Eight files still assert the refuted value

Found by `scripts/rediscovery_sweep.py` once code parameters were ranked separately
from named-object compounds — before that, this row sat below co-occurrence noise.
None of these mentions `[[137,1,21]]`, a refutation, or a retraction:


Two of them are the passes the synthesis explicitly refutes, still carrying the
stale value with no pointer forward. One is a file named *master theorem*.

**These are not edited here.** The repository's rule is that a failed claim gets a
retraction pass, not a quiet edit — and several of these are dated analysis files
whose value is partly as a record of what was believed when. The correct fix is a
forward pointer in each, which is a deliberate act by whoever owns them.
