\subsection*{Rank-24 root shadows and the Golay--tetracode glue bifurcation}

The exhaustive rank-$24$ carrier classification leaves exactly three Niemeier lattices
supporting the required pure $\Phi_9^4$ order-nine quotient to $W(3,3)$:
$E_8^3$, $E_6^4$, and $A_2^{12}$.  The new exact verifier computes the image of every
root in the projective quotient $L/(I-X)L\cong\mathbb F_3^4$.

The three root shadows are different:
\[

\]
with all forty points of $W(3,3)$ visible and no quotient-zero roots;
\[
E_6^4:\qquad 288=72_{\rm ker}+4\cdot54,
\]
where the four visible points form one $W(3,3)$ line; and
\[
A_2^{12}:\qquad 72=4\cdot18,
\]
again supported on one $W(3,3)$ line, with no quotient-zero roots.  In the $E_8^3$
carrier each individual $E_8$ factor already covers all forty points with six roots per
point, recovering the earlier Eisenstein six-to-one $E_8\to W(3,3)$ fibration.

The $72$ quotient-zero roots of the $E_6^4$ carrier split componentwise as
\[
4\,(A_2^3)=A_2^{12}.
\]
This is an equality of root-system type, not an identification of the full Niemeier
lattices.  It nevertheless provides a common $A_2^{12}$ root substrate on which the
$E_6^4$ and $A_2^{12}$ Niemeier overlattices can be compared exactly.

\[

\]
and each scalar pair over one of the four visible line channels contributes
\[
2\cdot27=54
\]

The Golay code has no weight-three word, so its glue adds no roots and the root system
remains $A_2^{12}$.
