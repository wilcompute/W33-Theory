# BT577 - Phase Cover Incidence Matrix

This certificate records the explicit incidence count for the nonzero phase cover.

Base incidences: 12960.

For every base incidence there are four scalar lifts from the two nonzero ternary scalars on each side.

The four lifts split evenly into two lifts on one nonzero sheet and two lifts on the other nonzero sheet.

Therefore:

- positive sheet size: 12960 times 2 = 25920
- negative sheet size: 12960 times 2 = 25920
- total nonzero cover size: 25920 plus 25920 = 51840

The sheet swap is the involution that flips one scalar sign. Applying it twice returns the original lift.

Checks:

- base count is 12960
- every base incidence has four lifts
- every base incidence contributes two lifts to each nonzero sheet
- each sheet has size 25920
- the total nonzero cover has size 51840
- the sheet-swap operation is an involution

Interpretation: the 51840 scale is an incidence cover over the 12960 projective support base. It is not an additional q equals 3 point-line duality.
