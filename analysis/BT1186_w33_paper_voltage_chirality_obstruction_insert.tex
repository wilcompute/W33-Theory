\begin{remark}[Voltage cover is nontrivial; chirality equality remains open]
\label{rem:voltage-chirality-obstruction}
The raw transport voltage defines a nontrivial binary cover of the complement
transport graph.  The base graph has parameters $(45,32,22,24)$ and $720$ edges,
so the binary lift has $90$ vertices and $1440$ lifted edge slots.  Its triangle
parity profile is
\[
  5280=3120+2160,
\]
with $2160$ odd triangles, so the voltage cannot be switched globally to the
trivial voltage.  This confirms that the missing sheet bit is real.  However,
the current data do not yet include a map from transport edges to BT748
root-triple fiber coordinates, so equality between this voltage and BT748
chirality is not claimed.
\end{remark}
