For quantum coarse graining, let $\mathcal E$ be the conditional expectation
onto observables constant on the sixteen computational-basis support blocks of

$X$-displacement marginal is constant on each support fiber; the exact
constraint system has rank $65$ on $81$ variables and a $16$-dimensional
solution space.  The $Z$-phase marginal is unrestricted for support
observables.  This is not a coherence-preservation theorem.
