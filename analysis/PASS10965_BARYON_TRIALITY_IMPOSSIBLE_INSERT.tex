\subsection{Pass 10965: baryon triality is structurally impossible}

% Repo prior art: Holotrade b81ef8c (operator locking); Passes 10960--10964.
Baryon triality $B_3=\exp(2\pi i(B-2Y)/3)$ would protect the proton without matter parity.
As a gauge symmetry it must be a $\mathbb{Z}_3$ character of the $U(1)$ charge lattice equal to
$B_3$ on every $q,u^c,d^c,e^c$ up to a hypercharge rotation; over $\mathrm{GF}(3)$ this is
inconsistent in all $215$ $W(3,3)$ $\mathbb{Z}_6$ models (zero-target control consistent in all
$215$).  The obstruction is $SU(5)$: in $214$ models single copies obey
$Q(u^c)+Q(e^c)=2Q(q)$ exactly, on which $B_3$ is $2$ and every hypercharge shift is $0$ mod $3$;
the last model has an explicit integer relation with the same property.  Only an
$R$-symmetry such as the anomaly-free $\mathbb{Z}_4^R$ remains as a route to proton stability.
