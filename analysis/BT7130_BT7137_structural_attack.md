## 7130 — blocker hypergraph is globally equivalent to the extremal problem

Fix the verified 51-set `S`. For an independent set `T` in the complement define

`B(T) = union_{v in T} (N(v) ∩ S)`.

Then `(S \ B(T)) ∪ T` is independent. Conversely, if any independent set `S'` is larger than `S`, put `T=S'\S`; every blocker of `T` in `S` must lie in `S\S'`, so `|B(T)| < |T|`. Therefore

> a larger partial ovoid exists anywhere **iff** some outside independent `T` has blocker deficiency `|B(T)|-|T| < 0`.

This upgrades the blocker formulation from a local-search diagnostic to an exact global reformulation. For q=9 the direct binary model has 820 variables, 32,310 outside-edge constraints, and 4,590 blocker implications. The bounded exact run did not close; Pass 7125 still supplies the rigorous radius statement `|T|<=8 => deficiency>=0`. No `alpha=51` claim is made.
