# Bonkers I — photon node-packing invariance

The user's processor intuition has a rigorous kinematic core.

For optical frequency \(\nu\),

\[
T=\frac1\nu,
\qquad
\lambda=\frac c\nu.
\]

If a model places \(N\) causal update sites in one wavelength and one optical period, define

\[
a_N=\frac{\lambda}{N},
\qquad
\tau_N=\frac{T}{N}.
\]

Then

\[
\boxed{
\frac{a_N}{\tau_N}=c.
}
\]

The node number cancels. Increasing \(N\) refines internal space and internal time together; it can increase representational complexity or throughput without changing the causal propagation speed.

If each site carries an independent \(d\)-state factor, the ideal tensor-product bookkeeping gives

\[
B_{\otimes}=N\log_2d,
\qquad
R_{\otimes}=N\nu\log_2d.
\]

The node density is

\[
\rho_N=\frac{N}{\lambda}=\frac{N\nu}{c},
\]

and therefore

\[
\boxed{
\frac{R_{\otimes}}{\rho_N\log_2d}=c.
}
\]

This is a precise version of “internal information motion mirrors external light motion”: \(c\) is the invariant throughput-per-information-density ratio.

There is a crucial capacity firewall. A single photon spread over \(N\) alternatives with a \(d\)-state internal label often has direct-sum dimension
