\paragraph{Pass 4592: the two self-orthogonal cubic axes are complementary restrictions of one simplex code.}
Pass~4575 gave the two rank-six binary codes
\[
 C_{36}=[36,6,16],\qquad C_{27}=[27,6,12]
\]
by evaluating the same $x\in U_6\cong\mathbb F_2^6$ on, respectively, the
$36$ anisotropic and $27$ nonzero singular vectors of the minus quadratic
space.  Keep the same message $x$ on both coordinate sets and concatenate.
For nonzero singular $x$ the two partial weights are $16+16$, while for
anisotropic $x$ they are $20+12$.  Hence every nonzero concatenated word has
weight $32$ and
\[
 \boxed{C_{63}=[63,6,32],\qquad W_{C_{63}}(z)=1+63z^{32}.}
\]
Thus $C_{63}$ is the binary six-dimensional simplex code and
$C_{63}^{\perp}=[63,57,3]$ is the Hamming code.  Its $63$ coordinates are
literally all nonzero vectors of $\mathbb F_2^6$; the original $27\mid36$
split is the singular/anisotropic coloring supplied by the minus quadratic form.
The full coordinate symmetry of the uncolored simplex is $GL(6,2)$, whereas
$O^-(6,2)\cong PGSp(4,3)$ is the subgroup preserving this quadratic coloring.

Choose a compatible $\mathbb F_4$-structure
$\mathbb F_2^6\cong\mathbb F_4^3$.  The standard hexacode
$\mathcal H_6=[6,3,4]_{4}$ has
\[
 W_{\mathcal H_6}(z)=1+45z^4+18z^6.
\]
Concatenating each $\mathbb F_4$ symbol with the binary inner simplex
$[3,2,2]$ produces a binary
\[
 \boxed{[18,6,8],\qquad 1+45z^8+18z^{12}.}
\]
The repository's explicit cyclic construction of the extended binary Golay
code $G_{24}$ contains exactly such a six-dimensional subcode: the first six
message generators vanish on six coordinates, and after restriction to the
other eighteen an explicit frozen coordinate permutation identifies the code
word-for-word with the binary concatenated hexacode.  This is an actual code
embedding, not a parameter match:
\[
 C_{36}\oplus_x C_{27}
 \longrightarrow [63,6,32]
 \longrightarrow \mathcal H_6
 \longrightarrow [18,6,8]\subset G_{24}.
\]
The middle arrow requires a choice of compatible $\mathbb F_4$ structure and is
therefore not claimed canonical under $O^-(6,2)$.

\paragraph{Pass 4604: the unary protected-to-cubic bridge is impossible at every degree.}
Under $G=PSp(4,3)$, the protected $V_8$ has nonzero orbits of sizes $135$ and
$120$, while the natural cubic $U_6$ has nonzero orbits of sizes $27$ and $36$.
Constant-fiber arithmetic rules out every nonzero orbit map except potentially
$135\to27$, which would require a block system of block size five.  The actual
stabilizer of a protected singular point has order $192$ and suborbit sizes
\[
 \boxed{1,1,1,12,12,12,32,32,32},
\]
so no block containing the point can have size five.  Therefore every unary
$PSp(4,3)$-equivariant set map
\[
 \boxed{V_8\longleftrightarrow U_6}
\]
is zero.  This supersedes the degree-$\le2$ polynomial no-go.  The Pass~4583
exterior-square bridge survives because it is intrinsically a two-input map
$(v,w)\mapsto v\wedge w$ through a larger module.
