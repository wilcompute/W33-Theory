Passes 5396–5403 · All-q apartment cycle tight frame

For a generalized quadrangle of order (q,q), let C be the signed flag-edge × Levi-apartment incidence matrix, with apartments the simple 8-cycles. A nonbacktracking five-edge Levi path has a unique apartment completion, and a distance-d pair of flag edges lies in exactly q^(4-d) apartments.

With all Levi edges oriented point→line, the cycle signs alternate, so

C Cᵀ = q⁴A0 − q³A1 + q²A2 − qA3 + A4 = N E₋₂,   N=(q+1)²(q²+1).

Hence the full apartment family is a tight frame for the q⁴-dimensional Levi cycle space. There are N q⁴ / 8 apartments; after unit normalization the frame bound is N/8.

At q=3: 160 flags, 1620 apartments, rank 81, and the signed kernel (81,−27,9,−3,1), exactly recovering the earlier W33 Levi cycle-frame theorem.

Boundary: the theorem concerns the full apartment family. It makes no claim that arbitrary apartment subsets are tight and implies no code-distance or physical fault-tolerance result by itself.
