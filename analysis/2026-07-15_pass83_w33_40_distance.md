## Corrected CSS Construction

Since A is not self-orthogonal over GF(2), the standard CSS requires a self-orthogonal subcode. The key insight from symplectic geometry:

The symplectic form Ω on GF(3)^4 defines a **null polarity** on the 40 isotropic points. Over GF(2), the symplectic structure descends to a symplectic form on the GF(2)-span of the incidence vectors.

**Correct construction:** Use A and A^T as the two parity check matrices, with the CSS orthogonality enforced by the null polarity:

```
H_X = A mod 2    (rows = lines; entries = point membership)
H_Z = A^T mod 2  (rows = points; entries = line membership)

H_X · H_Z^T = A · A   (since A = A^T for the incidence of a self-dual polar space)
```

For W(3,3), is the incidence matrix symmetric? A point p is on line l iff line l contains point p — so yes, A = A^T (the incidence relation is symmetric). Therefore:

```
H_X · H_Z^T = A · A^T = A² mod 2
```

Over GF(2), A² has diagonal entries = row_sum(A) mod 2 = 4 mod 2 = 0 ✓
Off-diagonal entries (A²)_{ij} = |{lines containing both i and j}| mod 2

- If i,j collinear: exactly 1 common line → (A²)_{ij} = 1 mod 2 = 1 ✗
- If i,j non-collinear: 0 common lines → (A²)_{ij} = 0 ✓

So A² mod 2 = B (the collinearity adjacency matrix of W(3,3)). This is NOT zero, so the naive construction fails.

## Fix: The Isotropic Subcode

Define the **isotropic subcode** as:
```
C_iso = {v ∈ GF(2)^40 : A·v = 0 mod 2} = ker(A mod 2)
```

This 1-dimensional code is spanned by **1** (all-ones vector). The minimum weight of **1** is 40.

For a valid CSS code, we need a pair (C₁, C₂) with C₂⊥ ⊆ C₁. The correct approach:

The 40 isotropic points of W(3,3) form the support of a **strongly regular graph** srg(40, 12, 2, 4). The eigenvalues of its adjacency matrix B are:
- λ₀ = 12 (multiplicity 1)

The **code defined by B over GF(2):** 
- The GF(2) null space of B has dimension = algebraic multiplicity of eigenvalue 0 over GF(2)
- Since 4 ≡ 0 (mod 2), the eigenvalue −4 ≡ 0 (mod 2) contributes a 12-dimensional null space!

So: **dim(ker(B mod 2)) = 12** (from the 12-dimensional eigenspace of −4).

## The [[40, 12, d]] Code

Using the collinearity adjacency matrix B (not the incidence matrix A), the CSS code is:

```
H_X = H_Z = B mod 2  (since B is symmetric)

CSS condition: B · B^T = B² mod 2 = ?

B² = (adjacency)² counts walks of length 2:
(B²)_{ii} = degree = 12 ≡ 0 (mod 2) ✓
(B²)_{ij} = |{common neighbors of i and j}|
```

For srg(40,12,2,4):
- i,j adjacent: 2 common neighbors → (B²)_{ij} = 2 ≡ 0 (mod 2) ✓
- i,j non-adjacent: 4 common neighbors → (B²)_{ij} = 4 ≡ 0 (mod 2) ✓

**B² ≡ 0 (mod 2) ✓** — so B IS self-orthogonal over GF(2)!

Therefore:
```
CSS from B: [[40, 2×12 - 40, d]] = [[40, -16, d]]
```

Wait — k = 2×dim(ker B) − n = 2×12 − 40 = −16 < 0. Something is wrong.

**Correction:** The CSS formula is k = dim(ker H_X) + dim(ker H_Z) − n when H_X · H_Z^T = 0.

With H_X = H_Z = B (40×40 symmetric, self-orthogonal):
```
k = 2 × dim(ker B) − rank(B over GF(2)) 
  = 2 × 12 − (40 − 12)
  = 24 − 28 = −4   ← still wrong
```

The correct formula: k = dim(ker H_X / im H_Z^T) + dim(ker H_Z / im H_X^T).

With H_X = H_Z = B:
```
k = 2 × dim(ker B / im B)
```
where im B ⊆ ker B (self-orthogonal). So dim(im B) ≤ dim(ker B) = 12.

rank(B mod 2) = 40 − 12 = 28, so dim(im B) = 28. But 28 > 12 = dim(ker B) — contradiction!

**Resolution:** im B ⊄ ker B in general. The self-orthogonality B·B^T = 0 means im(B^T) ⊆ ker(B), i.e. B(Bv) = 0 for all v. So im(B) ⊆ ker(B). But dim(im B) = 28 > dim(ker B) = 12 — contradiction.

**Recheck:** B·B^T = B² = 0 mod 2 implies that for any vector v, B(Bv) = 0, so im(B) ⊆ ker(B). We computed rank(B) = 28, so dim(im B) = 28. But dim(ker B) = 12. Then im(B) ⊆ ker(B) requires 28 ≤ 12 — impossible!

**Therefore B² ≠ 0 mod 2.** Let me recheck the srg(40,12,2,4) common neighbor counts:

For srg(40,12,2,4): λ=2 (common neighbors when adjacent), μ=4 (when non-adjacent).

- Adjacent pair: 2 common neighbors → 2 mod 2 = 0 ✓
- Non-adjacent pair: 4 common neighbors → 4 mod 2 = 0 ✓

Actually B² = 12I + 2B + 4(J − I − B) = 12I + 2B + 4J − 4I − 4B = 8I − 2B + 4J

mod 2: B² ≡ 0·I − 0·B + 0·J = **0 (mod 2)** ✓

So B² = 0 mod 2 IS correct. The rank contradiction must be reexamined.

**B² = 0 mod 2 implies im(B) ⊆ ker(B), so rank(B) ≤ dim(ker B) = 40 − rank(B)**, hence rank(B) ≤ 20.

This means dim(ker B mod 2) ≥ 20, not 12. The eigenvalue argument was wrong — we need the 2-rank, not the algebraic multiplicity over ℝ.

**2-rank of B for srg(40,12,2,4):** This is the GF(2)-rank of the symplectic strongly regular graph. Known result: **2-rank(B) = 20** for the W(3,3) collinearity graph.

So dim(ker B mod 2) = 20, and:
```
k = 2 × dim(ker B / im B) = 2 × (20 − 20) = 0   ← trivial!
```

The collinearity matrix gives a **trivial** code (k=0). Not useful.
