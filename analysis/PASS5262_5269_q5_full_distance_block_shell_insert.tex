\subsection{The $q=5$ apartment code has distance $625$}
Pass~5262 closes the remaining strict $q=5$ sector.  Let $K_0$ be the
$560$-dimensional zero-P-parity residual inside the product of the $325$ local
even P-component spaces.  On a minimum weight-eight footprint-dual support $D$,
the projection of $K_0$ has rank $134$, and deleting any one block of $D$ leaves
rank $134$.  Hence a nonzero $K_0$ word cannot meet $D$ in exactly one active
P block.  Since the complete $24{,}375$-word weight-eight dual shell is one
symplectic orbit, this no-singleton property holds for every shell check.
If $S$ is a nonzero P-block support of size $w$, the shell replication $600$ and
maximum pair codegree $25$ give
\[
  300w\le \sum_D { |S\cap D|\choose2}\le 25{w\choose2},
\]
so $w\ge25$.  Every hypothetical apartment word of weight below $625$ had
already been reduced to at most $15$ active even P blocks, a contradiction.
Therefore
\[
  \boxed{C_A(q=5)=[73125,625,625]_2}.
\]
Together with the Pass~5238 equality-shell theorem, the $936$ chamber stars are
exactly the minimum words.  This is a finite $q=5$ theorem, not an all-$q$
$q^4$ distance theorem.
