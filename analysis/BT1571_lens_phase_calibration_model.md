# BT1571 Lens-phase Calibration Model

On the centered OAM basis ell=-1,0,+1 with qutrit labels 2,0,1, qutrit S has omega-exponent signature [1,0,1].

A quadratic lens phase omega^(ell^2) has the same signature [1,0,1].

Thus the S/lens row is exact at the finite phase-signature level. Lab calibration is still required for mode overlaps and aberrations.
