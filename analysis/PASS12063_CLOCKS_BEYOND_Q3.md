# Pass 12063: clocks beyond q = 3

Claude track. Builds on 12059 and 12060.

## Setting

For general q, an observer is an F_{q²}-structure: J² = ν with ν a non-square, and JᵀΩJ = νΩ, so that C(J) = SL(2,q²).
At q = 3 with ν = −1 these are the Kramers reversals. All counts below are exact, from GAP with Sp(4,q) generated by
transvections of an explicit form.

## Results

| | q = 3 (control) | q = 5 |
|---|---|---|
| J / observers | 72 / 36 | 600 / 300 = q²(q²−1)/2 |
| \|C(J)\| | 720 | 15600 = \|SL(2,25)\| |

| clock pairs fixing an observer | collinear: the 3 mirror frames (12060) | **none** (collinear 80; non-collinear 24 or 96) |
| full point-stabiliser pairs | none (108 / 48) | none |

## Reading

- **The relativity principle holds at q = 3 and q = 5.** One clock fixes no observer.
- **The mirror rest frames are special to q = 3.** They need the normal clock group, which exists because SL(2,3) has a
  normal Q₈ of index 3.
- **Remark (Galois, classical).** Index-q subgroups of Stab(p) that contain U correspond to index-q subgroups of
  PSL(2,q). These exist only for q ∈ {2, 3, 5, 7, 11}, and only at q = 3 is the subgroup normal (V₄ ◁ A₄).
