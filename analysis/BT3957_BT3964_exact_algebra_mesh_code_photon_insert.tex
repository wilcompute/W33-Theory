\paragraph{Photon node-packing boundary.}

\[
T=\nu^{-1},\qquad \lambda=c/\nu.
\]
If $N$ internal update sites refine one wavelength and one period together,
\[
a_N=\lambda/N,\qquad \tau_N=T/N,
\]
then
\[
\boxed{\frac{a_N}{\tau_N}=c.}
\]

\[
R=N\nu\log_2d,\qquad \rho=N/\lambda,

\frac{R}{\rho\log_2d}=c.
