# BT1529 Tomotope 192 Assembly Test

The assembled carrier has 168 toroidal flags plus 24 K4 ground flags, giving 192.

It also decomposes as eight 24-flag packets:

- seven toroidal/Fano phase packets;
- one tetrahedral ground packet.

This is a flag-scale assembly test, not an abstract-polytope isomorphism theorem.
