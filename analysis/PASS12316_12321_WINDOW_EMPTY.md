**Correction to 12307.** The torsion phase acts through the translation e6 on Witten-twisted states, so it shifts their **momentum**
by ½. A lattice-valued Wilson line is not a freely acting translation, so windings stay integral. 12307's "winding ½" was wrong.

| states | level α′m²/4 | tachyonic for |
|---|---|---|
| n = ½, w = 0 | −1/6 + α′/(16R²) | R₆ > √(3α′/8) ≈ 0.61√α′ (the decompactified tachyonic parent returns) |
| w = 1, n = 0 (odd winding flips the shift) | −1/6 + R²/(4α′) | R₆ < √(2α′/3) ≈ 0.82√α′ |

The bounds overlap, so **there is no tachyon-free window**. The second row is the standard Scherk–Schwarz argument; the engine cannot
compute winding states.

**The whole family (12317).** All 15 brothers of the SM_810 lineage have the same right-moving vacua (−1/6 twice, −½ once), and none
has a tachyon at zero momentum and winding. The window argument applies to every one of them.

**Consequences (12318–12320).**

- Radius stabilisation, unification with the full spectrum and the vertex rule are not pursued: they concern a candidate this
  argument removes.
- The −1/6 vacua come from the twist alone, so every non-SUSY Z6-II model has them.
- Ordinary Standard-Model parents lose a generation (12180), Z2×Z6-I is closed (12199), and the SM_810 parents are tachyonic. So the
  Scherk–Schwarz route gives no three-generation model with a tachyon-free window on the covered geometries.
