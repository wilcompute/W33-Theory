# BT669 — Explicit K44 -> K33 Frame Map in the BT666 Fano Chart

This executes the next step after BT666--BT668: make the map

```text
K44 one-factorization frames -> six-frame K33 quotient
```

explicit in the same Fano/tomotope chart.

## 1. K44 in the Fano hinge chart

Use the BT666 hinge chart on `F2^3`.

The hinge-adjacent odd axes are

```text
O = {001,010,100,111}.
```

The even side is

```text
E = {000,011,101,110}.
```

The quotient graph is

```text
p ~ q  iff  p+q in O,
```

so

```text
K44 = Cay(F2^3, O)
```

with bipartition `E | O`.

## 2. Perfect matchings as permutations

Every perfect matching of `K44` is a bijection

```text
pi: E -> O.
```

After fixing an origin in `E` and identifying `O` with a translated copy of `E`, perfect matchings are exactly the `24` permutations of four symbols:

```text
Match(K44) ~= S4.
```

## 3. The canonical one-factorization

The canonical Fano/tomotope one-factorization is generated by the four odd Fano generators:

```text
001, 010, 100, 111.
```

For each `s in O`, define

```text
M_s = {(e, e+s): e in E}.
```

Then

```text
Frame_0 = {M_001, M_010, M_100, M_111}
```

is a one-factorization of `K44`: its four matchings are disjoint and partition all `16` edges.

In permutation language this frame is the Klein four subgroup

```text
V4 = {(), (12)(34), (13)(24), (14)(23)} < S4.
```

## 4. Six frames as S4/V4

The full set of `24` perfect matchings decomposes into six disjoint one-factorization frames:

```text
S4 / V4.
```

Thus

```text
24 perfect matchings = 6 frames * 4 matchings per frame.
```

Because `V4` is normal in `S4`, the frame set inherits the quotient group

```text
S4/V4 ~= S3.
```

This is the missing explicit frame map:

```text
K44 perfect matchings -> S4/V4 -> S3 six-frame set.
```

## 5. K33 root graph on the six frames

Let the six frames be the six elements of `S3`.

Connect two frames when their quotient differs by a transposition:

```text
g -- h  iff  g^{-1}h is one of the three transpositions in S3.
```

This graph is

```text
Cay(S3, {transpositions}) ~= K3,3.
```

The bipartition is the sign bipartition of `S3`:

```text
3 even frames + 3 odd frames.
```

So the exact quotient chain is

```text
K44 -> Match(K44)=S4 -> Frames=S4/V4=S3 -> Cay(S3, transpositions)=K3,3.
```

## 6. Attaching BT666 carrier labels

Use the BT666 dictionary

```text
011 <-> far,
101 <-> middle,
110 <-> active.
```

Choose the three even elements of `S3` as

```text
F+, M+, A+,
```

and the three odd elements as

```text
F-, M-, A-.
```

The metric matching

```text
F+--F-, M+--M-, A+--A-
```

is a choice of three transposition directions in the `S3` Cayley graph.

Its stabilizer is

```text
Aut(K3,3, metric matching) ~= D6 ~= W(G2).
```

## Result

The continuous combinatorial chain is now explicit:

```text
raw 4K4 complement
 -> secondary Q4 codec
 -> antipodal K44 quotient
 -> 24 perfect matchings
 -> 6 one-factorization frames S4/V4
 -> K33 = Cay(S3, transpositions)

```

## Boundary

This remains a secondary codec/frame quotient.  It does not turn the raw Levi complement into `Q4`, and it does not produce a real flag-level `W(G2)` action on all `160` Levi flags.
