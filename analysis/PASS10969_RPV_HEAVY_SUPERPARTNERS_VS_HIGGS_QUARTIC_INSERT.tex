\subsection{Pass 10969: harmless $R$-parity violation versus the Higgs quartic}

% Cross-track join: Passes 10960--10967 (Claude) and analysis/w33_two_susy_scales.py (physics track).
The FI-forced condensate regenerates dimension-four $R$-parity violation with $\lambda'\sim\lambda''
\sim\langle n\rangle/M_s\approx0.19$--$0.39$.  Heavy squarks make it harmless only if
$\tilde m\gtrsim6\times10^{14}$--$1.2\times10^{15}$\,GeV ($|\lambda'\lambda''|\lesssim10^{-27}(\tilde m/100\,
\mathrm{GeV})^2$).  Two-loop Standard-Model running from NNLO matching (control: $\lambda(M_{\rm Pl})=-0.0150$
against the three-loop fit $-0.0143$) puts the zero of the Higgs quartic at $3.2\times10^{10}$\,GeV for
$m_t=172.57$\,GeV.  MSSM matching with colour-breaking-safe stop mixing needs $\lambda(M_S)\ge0$, so
$M_S\ge10^{15}$\,GeV requires $m_t\le171.00$\,GeV, $5.4\sigma$ below the measured value on the
experimental error alone.  The same running refutes $\lambda_h(\mathrm{GUT})=+1/40$ (BT475), which would need
$m_t\approx166.9$\,GeV.
