\subsection{A full-group no-go for direct Schlaefli--W33 linear transport}
\label{subsec:schlafli-w33-no-go}

The existing generator-level constructions realize the same inner group
$G=PSp(4,3)$ on the 40 W33 points and on the 27 Schlaefli vertices.  Both actions
are transitive of rank three.  The W33 graph has spectrum
\[
 12^1\oplus2^{24}\oplus(-4)^{15},
\]
so its characteristic-zero permutation module is multiplicity-free with
\[
 \mathbb C^{40}\cong\mathbf1\oplus V_{24}\oplus V_{15}.
\]
The Schlaefli action has subdegrees $1,10,16$ and degree-$16$ orbital graph
$SRG(27,16,10,8)$ with spectrum
\[
 16^1\oplus4^6\oplus(-2)^{20},
\]
hence
\[
 \mathbb C^{27}\cong\mathbf1\oplus V_6\oplus V_{20}.
\]
The only common irreducible constituent is therefore the trivial module.  Schur's
lemma gives the exact obstruction
\[
 \boxed{\dim\operatorname{Hom}_{PSp(4,3)}(\mathbb C^{27},\mathbb C^{40})=1}.
\]
Thus every full-group equivariant linear map is a scalar multiple of the constant
all-ones channel; there is no nonconstant direct characteristic-zero linear transport
between the 27 and 40 carriers.  A nontrivial bridge must instead break to a proper
subgroup, be nonlinear, pass through a larger intermediate carrier, or use a modular
coefficient field, which is a separate representation-theoretic problem.
