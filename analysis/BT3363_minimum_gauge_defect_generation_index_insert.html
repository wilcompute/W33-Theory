Minimum gauge defects generate every flat connection

Each of the 240 filled port triangles contributes a two-dimensional flat plane over F3, generated by its weight-two defects. Because the filled triangles partition all 720 edges, the minimum defects span the complete flat C35 connection space.

Exact dimensions: dim Z1 = 2400, dim B1 = 220, and dim H1 = 2180. Thus every switching class can be assembled from minimum defects. This is a generation theorem, not a unique-decoding or multi-fault-correction claim.
