# BT1587 OAM Recenter Transaction ABI

The full 216-element internal Clifford/OAM shell is nine affine recentering shifts over the 24 centered BT1495 transaction words. The class profile is `24,48,48,96` for centered, OAM-only, phase-only, and mixed shifts. One full operation sweep uses `216*72=15552` ticks; the five-gate witness sweep uses `77760` ticks.
