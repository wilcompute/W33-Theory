Global cover closure and the exact hypercube boundary

The complete census contains 3,547,800 exact covers in 327 PSp(4,3) orbits. The closed Hamming component contributes 1,574,640 covers; its exact exterior complement contains 1,973,160 covers in 192 orbit classes, split by stabilizer order as 120 + 57 + 15.

The ternary cover graph H(5,3) is not an ordinary hypercube subgraph: it contains triangles. It does have an exact block-one-hot host in the distance-two graph of Q15, with binary distance exactly twice ternary Hamming distance. This is distinct from the toroidal-knight controller Q4 and the secondary 16-state complement codec.

The rational-dual batch is reduced exactly from 204,287,050 to 98,191,335 coordinates. The chromatic boundary remains 10 ≤ χ(H) ≤ 11.
