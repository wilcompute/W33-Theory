## 12274: the bicharacter

Add a lattice vector λ to the Wilson lines in a set S. In each sector h the set of left momenta is unchanged, because the coset
Λ + V_h + σ_h λ equals Λ + V_h. The projection phase of g on sector h then changes by

    B(g, h) = ½ (σ_g V_h·λ − σ_h V_g·λ)  mod 1,      σ_g = Σ_{x∈S} m_x(g).

This is an antisymmetric bicharacter (λ² is even), i.e. a discrete-torsion phase. For torsion from lattice shifts see Plöger et al.,
hep-th/0702176; cited, not claimed. In-corpus prior art is **12199b**: a lattice-valued Wilson line acts trivially iff all its
products with the shifts and lines are even. That is the special case of a pure lattice line. B generalises it to shifts of existing
lines, and shows that **only commuting pairs matter**.

B was evaluated exactly on every commuting pair of space-group elements for the 320 relabellings of 12271:

| | result |
|---|---|
| B = 0 on all commuting pairs ⇒ spectrum unchanged | **232/232** |
| spectrum changed ⇒ B ≠ 0 somewhere | **61/61** |
| consistent Z2×Z2: B ≠ 0 ⇒ changed | 41/44 |

The 3 exceptions do have massless fields in their torsion sectors (248–288 of them). So my first guess, "torsion only off the
massless spectrum", is **refuted**. B ≠ 0 is necessary for a change but not sufficient. *Suspected:* the sign exchanges states with
identical quantum numbers.

## 12275: why order three has none

On T6/Z3 the centralizer of a twisted element h is generated by h itself and the central Witten element w.

- B(hᵏ, h) = 0 by antisymmetry. The labels of hᵏ differ from k·f by multiples of 3W; that is harmless iff 3W·λ is even, which is
  (7f) for the shifted model.
- B(w, h) = ½ σ_h V0·λ is an integer iff V0·λ is even, which is (7d).

**So on T6/Z3 a lattice shift keeps the Plöger conditions iff it induces no torsion.**

Check over 397 random (model, λ): consistent shifts give B = 0 in 37/37; violating shifts give B ≠ 0 in 360/360. This explains
983/983 (12267) and 160/160 (12271).

**General form.** A commuting pair can carry torsion only if the orders of its two elements share a factor.

- **Z6-II, order-2 lines on the SU(2)² torus.** Only θ², θ⁴ (order 3) commute with the translations e5, e6. Their phase
  B(e5, (θ², f)) = (2V·λ + (f3+f4)W3·λ)/2 is an integer once the shifted model is consistent.
- **Z6-II, order-3 lines on the SU(3) torus.** θ³ (order 2) commutes with them; again the orders are coprime.

## 12277: SM_2496 (non-SUSY Z6-II)

Here the order-2 Witten element commutes with the translation e5, so torsion is possible.

- **Classes:** 1152 classes of W5 shifts, of which 16 are consistent.
- **Result:** the spectrum depends on **one bit**, V0·λ mod 2. Eight brothers are identical to the control; the other eight share
  one new spectrum.

| | original | brother (V0·λ odd) |
|---|---|---|
| fields | 790 | 804 |
| tachyon-type states | 8 | 14 |
| fermions | 220 + 220 | 220 + 220 |
| θ³ (Witten-untwisted) | — | 12 fermions ↔ 12 scalars swapped |

The induced phase is B(w, e5) = V0·λ/2: a fermion-number phase tied to a lattice translation. That is a Scherk–Schwarz-type twist
along the SU(2)² torus, using the same order-2 translations as 12177/12180 (cited). The Scherk–Schwarz reading is *suspected, not
derived.* The brother is a distinct, still tachyonic vacuum, not a cure.
