# BT1578 Full Centered-basis Calibration Matrix

The complete core gate set I, X, Z, F3, and S is calibrated on the centered OAM basis ell=-1,0,+1 with labels 2,0,1.

I, X, Z, and S are sparse monomial matrices; F3 is the full three-mode mixer.

This is exact finite qutrit calibration, not a loss model.
