\subsection{Fixed-point obstruction and the cocycle-support code (Passes 4490--4492)}
\label{sec:pass4490-fixed-point-cocycle}

Pass~4488 proved computationally that the apartment extension
\[
 0\to K/J\;(29)\to E=M/J\;(39)\to V=M/K\cong H_{10}\;(10)\to0
\]
does not split $PSp(4,3)$-equivariantly.  Pass~4490 reduces the $1660$-equation
certificate to a fixed-point obstruction.  The transitive 40-line permutation
module $M$ has fixed space exactly $J=\langle\mathbf1\rangle$, hence
\[
 \boxed{E^{PSp}=0.}
\]
By contrast, the protected $H_{10}=1\mid8\mid1$ module has a unique fixed line,
so
\[
 \boxed{V^{PSp}\cong\mathbb F_2.}
\]
An equivariant section would have to lift the nonzero fixed class of $V$ to a
nonzero fixed class of $E$, which is impossible.  Equivalently, the connecting
map in fixed-point/cohomology
\[
 V^{PSp}\longrightarrow H^1(PSp(4,3),K/J)
\]
is nonzero on the one-dimensional fixed line.

Pass~4491 localizes a representative of this extension cocycle.  For a lift
$e\in E$ of the protected fixed vector $v\in V$, define
\[
 c_g=G_E(g)e-e.
\]
The $PSp(4,3)$-module generated by the defects $c_g$ has dimension $23$ and is
exactly
\[
 \boxed{(K\cap R^\perp)/J,}
\]
where $R=\ker N$ is the route code and $R^\perp=\operatorname{rowspace}N$.
Its ambient invariant chain
\[
 J<U<I<K\cap R^\perp
\]
has dimensions
\[
 1<9<10<24,
\]
so the cocycle support has profile
\[
 \boxed{8\mid1\mid14.}
\]
Affine support equations show that this cocycle cannot be gauge-shifted into
$I/J$ (dimension nine): the coefficient and augmented ranks differ by one.
It can be represented inside $(K\cap R^\perp)/J$.  Hence the route-side
six-dimensional factor of the full radical profile $8\mid(6\oplus1)\mid14$
is not required by this fixed-line obstruction.

Pass~4492 resolves the 23-space in terms of older certified code objects.  Let
$C=\ker N^T$ be the Pass-201 $[40,15,8]$ sentinel code and let
$U=R\cap R^\perp$ be the Pass-176 route hull.  Incidence restricts to the exact
sequence
\[
 \boxed{0\to U\;(9)\to K\cap R^\perp\;(24)
 \xrightarrow{\;N\;}C\;(15)\to0.}
\]
The image is all of $C$ and the kernel is exactly $U$.  Since $J\subset U$,
\[
 \boxed{0\to U/J\;(8)\to(K\cap R^\perp)/J\;(23)
 \to C\;(15)\to0.}
\]
Pass~176 owns the route-hull $U/J$ eight-core; Pass~201 owns the sentinel code;
Pass~187 owns the fixed-line/irreducible-14 filtration of $C$.  The new
conclusion is their exact incidence weld inside the apartment nonsplitting
cocycle: the profile $8\mid1\mid14$ is structurally
\[
 \boxed{\text{route-hull }8\;\mid\;\text{sentinel }(1\mid14).}
\]
These are module/cohomology statements only.  They do not identify a physical
error current, an energy-transfer channel, or a hardware fault path.
