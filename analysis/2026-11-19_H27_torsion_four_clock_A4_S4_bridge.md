# H27's torsion gerbes carry a four-clock A4/S4 action

**Date:** 2026-11-19. **Status:** exact finite-group theorem, tested for all 48 invertible 2-by-2 matrices over F3. Geometric realization is **not claimed**.

## New bridge beyond the integral torsion theorem

The earlier calculation gives
`H^3(Y7;Z)_tors = (Z/3)^2`, generated by
`a cup eta` and `b cup eta`.
There are nine classes total, eight nonzero. Modding the nonzero ones
by multiplication by `-1` produces exactly four projective rays:
```
P^1(F3) = {[1:0], [0:1], [1:1], [1:2]}.
```
This is the **same abstract four-point projective line** that labels
the four qutrit Hesse/MUB striations and the four tetracode clocks in
`papers/forty_points/main.pdf` (Section 4). It is a structural
correspondence, not an assertion that a gerbe is a physical clock.
Opposite order-three gerbe classes are not automatically gauge-equivalent.

## Exact H27 automorphism lift

Use `(a,b,c)*(A,B,C)=(a+A,b+B,c+C+a*B)` over F3. Set the
Weyl-symmetric central coordinate `t=c-(ab)/2`, where
`1/2 = 2 mod 3`. The law becomes
```
(v,t)*(w,s) = (v+w, t+s+(1/2) det(v,w)).
```
For **every** `M in GL(2,3)`, define
`(v,t) -> (Mv,det(M)t)`. This preserves the group law, since
`det(Mv,Mw)=det(M)det(v,w)`.
In ordered coordinates this is the exact correction
```
(a,b,c) -> (u,v,det(M)*(c-2ab)+2uv),
(u,v)=M(a,b).
```
All `48 * 27 * 27` group-law preservation identities pass.

- The **24** determinant-one matrices fix the H27 center.
- The **24** determinant-two matrices invert the center.
- On `P^1(F3)`, the center-preserving `SL(2,3)` action has image
  `PSL(2,3) ≅ A4`, 12 even permutations of four rays.
- The full `GL(2,3)` action has image `PGL(2,3) ≅ S4`, all 24
  permutations, with determinant-two transformations exactly the odd ones.
- In both cases the projective kernel is `{+I,-I}`.

Under a torus automorphism `M`, the degree-one generators transform
by the pullback `M^T`. But `a cup b=3 eta` forces `eta` to
transform by `det(M)`, so the **integral degree-three torsion pair**
transforms by `det(M) M^T`. That determinant twist is essential on
individual torsion classes; projectivization removes it because
`det(M)=+/-1` is a scalar over F3. Hence the four projective rays
have exactly the A4/S4 structure above.

## Interpretation firewall

The group-theoretic bridge identifies an abstract **tetrahedral
orientation structure on four discrete-flux directions**. It does not
show that the entire `GL(2,3)` action is an isometry of a chosen metric
on `Y7`, or that every automorphism lifts to a physically consistent
`E8` gauge background. Nor does it identify `B` and `-B` as
physically equivalent. The determinant-two sector resembles the
center-conjugating/antiunitary operation in qutrit Clifford theory, but
does not by itself select a direction of time or chirality.
