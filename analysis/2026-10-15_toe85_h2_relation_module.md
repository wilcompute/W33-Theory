## Second exact result: binary semisimple decomposition

Because the characteristic 2 does not divide the group order 27, Maschke's theorem applies. Subgroup averaging is particularly simple because `3=9=27=1` in F2.

Write `Z` for the three-element center and `L` for each of the four maximal abelian order-nine subgroups containing Z. Project onto invariant subspaces with the exact operators

```
P_Z = sum_{z in Z} rho(z),    P_H = sum_{g in H27} rho(g),
P_L = sum_{g in L} rho(g).
```

Computed ranks are `rank P_Z=10`, `rank P_H=2`, and `rank P_L=4` for **each** of the four L. The differences `P_L-P_H` each have rank 2 and their combined images have rank 8. The complementary center-nontrivial piece `I-P_Z` has rank 6.

Moreover, each of the 63 nonzero vectors in this 6D piece generates the full 6D submodule under H27. This exhaustively proves irreducibility of that component.

Thus, as an F2[H27]-module,

```
H2(F2) = 1^2  (+)  V_1 (+) V_2 (+) V_3 (+) V_4 (+) W_6,
dim:        2   +     2   +   2   +   2   +   2   +  6 = 16.
```

Here each V_i is a distinct 2-dimensional nontrivial simple module inflated from `H27/Z ~= F3^2`, corresponding to one maximal abelian/Pauli direction, while W_6 is a **faithful irreducible** binary Heisenberg module with nontrivial central action. This faithful summand is the field-restricted 3-dimensional Schrödinger-type representation over F4; that representation-theoretic description follows from the characteristic-2 irreducible classification, whereas the projector ranks and 63-vector test are direct finite computations.

**Interpretation:** all four Pauli/MUB directions occur symmetrically as 2D summands in binary H2, while the center-sensitive 6D piece carries the genuinely nonabelian representation.
