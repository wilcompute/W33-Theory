## Goal
Derive a quantum CSS code directly from the point-line incidence structure of W(3,3) = Sp(4, GF(3)).

---

## W(3,3) Combinatorial Data

```
Points:    v = (3^4 - 1)/(3 - 1) = 40
Lines:     b = 40  (self-dual polar space for rank-2 symplectic)
Points per line:  k_line = 4   (lines are 1-spaces in PG(3,3))
Lines per point:  r = 4
Collinearity degree: k_col = 12  (each point collinear with 12 others via 4 lines × 3 others)
```

The incidence matrix A is a 40×40 (0,1)-matrix with row and column sum 4.

---

## CSS Code Construction

Let H be the 40×40 incidence matrix of W(3,3) over GF(2).

For a CSS code we need H_X · H_Z^T = 0. The natural choice for a self-orthogonal structure:

```
H_X = A  (points vs lines incidence)
H_Z = A  (same matrix = self-dual construction)
```

Orthogonality check: A · A^T = ?

For W(3,3), two distinct points are either:
- **Collinear:** lie on a common line → exactly 1 common line (since each pair of collinear points determines exactly 1 line in W(3,3))
- **Non-collinear:** do not lie on any common line

So (A · A^T)_{ij} =
- i = j: 4 (row sum of A, number of lines through point i)
- i ≠ j collinear: 1 (exactly one common line)
- i ≠ j non-collinear: 0

Over GF(2):
```
A · A^T = I + B_collinear  (mod 2)
```
where B_collinear is the collinearity graph adjacency matrix of W(3,3).

**This is NOT zero in general — A is NOT self-orthogonal over GF(2).** So the naive CSS doesn't work.

---

## Fix: Use Sub-matrix or Twisted Construction

### Option 1: CSS from A over GF(3)

Over GF(3), the inner product structure is preserved by the symplectic form. The symplectic polarity maps each point to its orthogonal complement (set of non-collinear points = 27 points for each of 40 points in W(3,3)).

The CSS over GF(3) (qutrit CSS) uses:
```
H_X = A over GF(3)
H_Z = J - A over GF(3)  (complementary incidence)
```

Here J is the all-ones matrix. This gives H_X · H_Z^T = A(J-A)^T = AJ^T - AA^T.

### Option 2: Hypergraph Product of W(3,3)

Take the hypergraph product of A with itself:
```
H_X = [A ⊗ I₄₀, I₄₀ ⊗ A^T]  (dimension: ? × (40²+40²))
H_Z = [I₄₀ ⊗ A, A^T ⊗ I₄₀]  (dimension: ? × (40²+40²))
```

This gives a [[2×40², k, d]] CSS code where:
```
n = 2 × 1600 = 3200
k = k(A)²  where k(A) = dim(ker A) over GF(2)
```

The 2-rank of A is needed. For W(3,3), the 2-rank is known:
- A has eigenvalues related to {4, 1, -3} for the incidence matrix
- Over GF(2): 2-rank(A) = 40 - dim(null space of A mod 2)

## 2-Rank of W(3,3) Incidence Matrix

The characteristic polynomial of A (as integer matrix) factors using the eigenvalues of the strongly regular graph srg(40, 12, 2, 4) (the point graph of W(3,3)):

```
Eigenvalues of point graph: 12 (once), 2 (27 times), -4 (12 times)
```

The eigenvalues of the incidence matrix A itself:
- λ = 4 (for the uniform vector): multiplicity 1
- The other eigenvalues come from the symplectic space structure

**Key result (known):** The 2-rank of the symplectic polar space incidence matrix Sp(2r, q) for q odd is:
```
2-rank(W(3,3)) = v - 1 = 39  (for the point-line incidence matrix)
```

This means the null space over GF(2) has dimension **1**, spanned by the all-ones vector.

---

## The Direct [[40,2,d]] Code

With a 1-dimensional null space, using the CSS construction:

```
k_CSS = dim(ker H_X) + dim(ker H_Z) - n   (for self-orthogonal case)
```

But since A is not self-orthogonal, the correct formula uses the quotient:
```
k = dim(ker H_X / im H_Z^T) + dim(ker H_Z / im H_X^T)
```

For the balanced case with 2-rank = 39:
```
dim(ker A) = 40 - 39 = 1
k_CSS = 2 × 1 - 0 = 2  (estimated)
```

**Candidate code: [[40, 2, d]] from W(3,3) incidence, over GF(2)**

Distance d is bounded below by the minimum weight in ker(A) / im(A^T).
