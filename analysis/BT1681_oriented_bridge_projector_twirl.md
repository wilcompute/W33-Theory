# BT1681 — Oriented Bridge Projector Twirl

## Purpose

BT1675 showed that the all-positive uniform edge-support twirl has zero Levi
\(H_1\) content. BT1681 asks the more refined question: what happens if we twirl
an **oriented 8-cycle subspace projector** instead of an all-positive support
vector?

## Setup

The projective symplectic action generated by transvections over \(\mathbb F_3\)
has order

\[
25920,
\]

with the full symplectic group order

\[
|\mathrm{Sp}(4,3)|=51840
\]

and center kernel size 2.

For the W33 Levi complex,

\[
|E|=160,
\qquad
|V|=80,
\qquad
\operatorname{rank}D=79,
\qquad
\dim H_1=81.
\]

## Fixed bridge subspace

The fixed gauge selects 8 oriented cycles.  Its subspace projector has

\[
\operatorname{tr}P_{\rm bridge}=8,
\]

idempotence residual

\[
1.3976951616924471\times10^{-15},
\]

and Hodge containment residual

\[
3.8818873972021084\times10^{-16}.
\]

So the selected bridge really is an 8-dimensional subspace of Levi \(H_1\).

## Automorphism twirl

Averaging this oriented subspace projector over the projective symplectic group
gives

\[
\overline P_{\rm bridge}
\simeq
\frac{8}{81}P_{H_1}.
\]

The computed Frobenius error is

\[
1.0598553943057821\times10^{-14},
\]

with relative error

\[
1.1923373185940048\times10^{-14}.
\]

The averaged trace is

\[
7.999999999999972.
\]

The nonzero eigenvalue is

\[
\frac{8}{81}=0.09876543209876543,
\]

with multiplicity

\[
81.
\]

## Interpretation

This cleanly reconciles BT1675 and BT1677:

- all-positive support twirling kills \(H_1\);
- oriented subspace twirling preserves the \(H_1\) trace but erases the chosen
  gauge basis.

Thus the natural automorphism-averaged oriented bridge is not a sparse embedding.
It is the isotropic density

\[
\boxed{\frac{8}{81}P_{H_1}.}
\]

## Boundary

The computation is numerical over the generated projective symplectic action.  It
strongly supports the Schur/isotypic formula; a formal proof would identify the
Levi \(H_1\) representation component explicitly.
