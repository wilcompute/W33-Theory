All-odd footprint rank closed — and a binary CSS family drops out

Exact theorem for every odd prime power q. The binary P-component footprint image is no longer an experimentally anchored mystery:

im₂(F) = CW⊥, so rank₂(F)=q(q²+1)/2 and ker₂(Fᵀ)=CW, where CW is the binary W(3,q) line-incidence code.

The missing argument is module-theoretic. Lataille–Sin–Tiep prove that CW⊥/<1> is simple in characteristic two. Every footprint block is orthogonal to every W-line, the sum of all footprint columns is the all-one vector, and one block is nonconstant. Therefore the footprint span must be the whole of CW⊥.

This closes the former three-way conjecture simultaneously:

rank₂(F)=g ⇔ ker₂(Fᵀ)=CW ⇔ K₀=Dq.

The complete minimum shell is now also a spanning shell. Pass 5189 had already classified all minimum words of CW⊥ as the dual grids H∪H⊥, of weight 2(q+1). Those words are exactly the footprint columns, hence for odd q they generate the full code:

[(q+1)(q²+1), q(q²+1)/2, 2(q+1)]₂.

Because CW⊥ ⊂ CW, the same footprint code gives a binary point-code CSS family

[[(q+1)(q²+1), q²+1, q+1]]₂, beginning with [[40,10,4]]₂, [[156,26,6]]₂, and [[400,50,8]]₂.

Boundary. This does not solve the q=11 dual weight-20/d=121 problem, the Hoffman shortened-code distance in {28,32,36,40}, or any fault-tolerance/hardware threshold. The binary point CSS family is distinct from the ternary edge CSS [[240,81,3]]₃.
