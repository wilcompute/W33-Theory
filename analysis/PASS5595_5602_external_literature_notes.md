# Pass5595–5602 external literature notes

These references are background and prior-art boundaries, not evidence for the repo-specific theorems.

1. **Meagher–Spiga, _An Erdős–Ko–Rado theorem for the derangement graph of PGL(2,q) acting on the projective line_**, arXiv:0910.3193. This is direct prior art for fixed-point/derangement relations in the projective-line action. It does not give the Reye/Segre incidence identification or the binary determinant-coset duality proved in this packet.

2. **Couvreur–Duursma, _Evaluation Codes from smooth Quadric Surfaces and Twisted Segre Varieties_**, arXiv:1101.4603. This explicitly treats hyperbolic quadric surfaces through the product/Segre geometry of `P^1 x P^1`, supporting the standard geometric background for the two-ruling carrier. It does not supply a Lorentzian or physical interpretation.

3. **Hollmann–Xiang, _Pseudocyclic association schemes arising from the actions of PGL(2,2^m) and PΓL(2,2^m)_**, arXiv:math/0503570. This is nearby prior art showing that projective linear group actions on conic-related finite geometries naturally produce association schemes. The carrier and characteristic differ from Pass5599, so it is not a citation for the specific fixed-point fusion formulas here.

4. **Kaya, _New extremal binary self-dual codes of lengths 64 and 66 from bicubic planar graphs_**, arXiv:1604.00486. The paper contains a Type-I self-dual `[16,8,4]` code with weight distribution `1+12 z^4+64 z^6+102 z^8+64 z^10+12 z^12+z^16`, numerically identical to the measured q=3 projectivity-code enumerator. This is **not** a code identification: the projectivity code is not self-orthogonal because two PSL2(3)=A4 permutation rows may meet in one projective point. The shared enumerator is therefore formally-self-dual data only and is recorded as a killed small-q identification rather than promoted.

5. **Kishnani–Kundu–Mishra, _Products of conjugacy classes in SL2(k) and PSL2(k)_**, arXiv:2305.09886. This is relevant background for the remaining Pass5599 symbolic problem: converting the computationally verified 0/1/2-fixed-point fusion into an all-q proof by counting products of split, nonsplit and unipotent classes.

## Search boundary

The search performed for this packet found literature on projective-line derangement graphs, PGL/PSL designs, conic association schemes, hyperbolic-quadric codes and formally self-dual binary codes. I did not find a source stating the exact combination proved here: the Reye/Klein-V4 permutation-action intertwiner, its F4 short-root-pair realization, the projection of the projectivity code from the W-line/footprint kernel, or the all-odd-prime-power opposite-determinant isoduality. This absence is **not a novelty claim**; it records only the scope of this search.
