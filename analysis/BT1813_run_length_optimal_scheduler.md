# BT1813 — Run-Length Optimal Scheduler Theorem

BT1808 gives three phase rows for every directed W33 edge. For a run of length \(L\) using one fixed directed edge, some row must be used at least

\[
\left\lceil L/3\right\rceil
\]

times. The round-robin rule over the three rows attains this bound for every \(L\).

Thus the BT1808 three-slot schedule is minimax-optimal for repeated use of a fixed directed relocation edge.

## Scope

This is an exact finite scheduling statement for a fixed directed edge and a stated traffic model. It is not a claim about every possible workload.
