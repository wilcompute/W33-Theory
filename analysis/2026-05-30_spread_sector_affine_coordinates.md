# Spread-Sector Affine Coordinates

Date: 2026-05-30

This upgrades the previous spread-sector fiber-label theorem from a bijection to an explicit coordinate system.

Previously we proved:

```text
Fix anchor p and anchor line L.
For any allowed affine direction d in p^perp \ L, the nine spreads containing L biject with the nine affine lines of direction d in AG(3,3).
```

Now we assign actual F3^2 coordinates to those nine labels.

## Affine quotient

At an anchor p, the affine bulk is

```text
AG(3,3) = PG(3,3) \ p^perp
```

with 27 points.

A chosen affine direction d determines a parallel class of affine lines. The nine affine lines of direction d are the cosets of the one-dimensional subspace generated by d:

```text
AG(3,3) / <d> ~= F3^2.
```

Therefore the nine line labels should be coordinatizable by pairs

```text
(a,b) in F3^2.
```

## Coordinate construction

The verifier chooses two independent linear functionals

```text
ell_1, ell_2
```

that annihilate both the anchor vector p and the direction d.

For an affine line parallel to d, the pair

```text
(ell_1(x), ell_2(x))
```

is constant along the line. Thus each parallel affine line receives one F3^2 label.

## Verified result

For the canonical anchor, the verifier checks all:

```text
4 anchor-line sectors
9 allowed directions per sector
```

For every sector and every direction, it verifies:

```text
there are 9 parallel affine lines,
those lines realize all 9 F3^2 labels,
the 9 spreads in the sector realize all 9 labels exactly once.
```

So the coordinate-level theorem is:

```text
spread labels in a fixed sector = F3^2 affine quotient coordinates.
```

## Meaning of 36=4*9

The identity

```text
36 = 4 * 9
```

is now no longer just a sector count.

It means:

```text
4 = choice of anchor/memory line through p
9 = explicit F3^2 coordinate label in an affine quotient AG(3,3)/<d>
```

So the exact spread/MUB-frame layer is:

```text
four memory-line sectors times nine affine quotient coordinates.
```

## Relation to the projection fiber

The projection theorem gave:

```text
PG(5,3) -> PG(3,3)
```

with 9-point fibers over each W33 anchor:

```text
364 = 40*9 + 4.
```

The symplectic fiber theorem showed each 9-point fiber is an affine F3^2 plane with four directions.

This theorem shows the same F3^2 coordinate type appears inside the spread sector:

```text
nine spreads in a sector = nine affine quotient labels.
```

So the same finite object appears in two roles:

```text
PG(5,3) projection fiber: F3^2 points
spread sector: F3^2 quotient-line labels
```

## Compressed theorem

```text
For fixed p, L, and d, the nine spreads containing L are labeled by the quotient AG(3,3)/<d>. Two linear functionals annihilating p and d give explicit F3^2 coordinates. Across every sector and allowed direction, the nine spreads realize each coordinate exactly once. Hence 36=4*9 is four memory-line sectors times an explicit affine F3^2 coordinate system.
```
