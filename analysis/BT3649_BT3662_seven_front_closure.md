## 1. Degree-three covering integrality

Let \(T\in\{0,1\}^{240\times5040}\) be the cubic dependency incidence matrix. Every column has weight three and every row has weight 63. The fractional transversal LP has exact primal and dual witnesses

\[
x=\frac13\mathbf1_{240},\qquad y=\frac1{63}\mathbf1_{5040},
\]

both of value 80. Thus \(\tau^*=80\).

Equality cannot be integral. A binary 80-set hitting all 5,040 triples would have total incidence \(63\cdot80=5040\), so every constraint would be tight: \(T^Tx=\mathbf1\). But \(TT^T=63I+D\) has minimum eigenvalue 45 and rank 240, hence this system has the unique real solution \(x=\frac13\mathbf1\). Therefore

\[
\boxed{\tau\ge81},\qquad \frac{\tau}{\tau^*}\ge\frac{81}{80}.
\]

This is the first exact integral obstruction supplied by the cubic deck. It is not a covering-radius endpoint theorem.
