\subsection*{Passes 5074--5081: coarea derivative, $q=4$ shell rigidity, quadratic order, and root-direction geometry}
For a binary Levi cohomology class, each opposite-pair chart with $q+1$ geodesics carries a cut of $K_{q+1}$.  If its smaller side has size $s_O$, then the local apartment weight is $s_O(q+1-s_O)$, and because every apartment lies in exactly four such charts,
\[
 4\,\mathrm{wt}(x)=\sum_O s_O(q+1-s_O).
\]
Thus the remaining all-$q$ distance theorem $d=q^4$ is reduced to the block-support inequality $A(x)\ge4q^3$ for every nonzero class.  A chamber class attains equality: it has $q^4$ apartments and exactly four role-families of $q^3$ active charts.  The identity $\frac{d}{dq}q^4=4q^3$ therefore has a precise discrete coarea shadow, but $q$ is not being promoted to a continuous physical coordinate.

At $q=4$ the minimum code is already $[13600,256,256]_2$.  The entire local-minimum sector is now rigid: after fixing one selected apartment, its four active charts give $16$ singleton-cut seeds; exact propagation leaves eight solutions and eight contradictions, and the eight solutions are exactly the eight chamber stars through that apartment.  Hence any non-chamber weight-$256$ word must contain a heavier $2|3$ chart.  If there are $A_2=2t$ such charts, then $A_1=256-3t$ and the total active-chart count is $256-t$.  The heavy-chart sector remains the only unresolved part of the $q=4$ minimum shell.

This is an arithmetic lattice bridge, not a new group-equivariant geometric identification.
