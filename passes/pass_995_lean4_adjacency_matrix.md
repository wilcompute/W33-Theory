## Construction via Symplectic Form

The symplectic polar graph Sp(4,3) has vertices = nonzero vectors in F₃⁴ modulo scalar multiplication = elements of PG(3,3). Two vertices [u], [v] are adjacent iff ω(u,v) = 0 AND [u] ≠ [v], where ω(x,y) = x₁y₂−x₂y₁+x₃y₄−x₄y₃.

### Lean 4 Implementation

```lean4
-- W33Theory/AdjacencyMatrix.lean
import Mathlib.Data.ZMod.Basic
import Mathlib.LinearAlgebra.Matrix.Determinant
import Mathlib.Combinatorics.SimpleGraph.Basic

namespace W33Theory

/-- The field F₃ -/
abbrev F3 := ZMod 3

/-- Nonzero vectors in F₃⁴, as 4-tuples -/
def Vec4 := {v : Fin 4 → F3 // v ≠ 0}

/-- The symplectic form on F₃⁴ -/
def symp (x y : Fin 4 → F3) : F3 :=
  x 0 * y 1 - x 1 * y 0 + x 2 * y 3 - x 3 * y 2

/-- Projective equivalence: x ~ y iff x = c·y for some nonzero c ∈ F₃ -/
def projEq (x y : Vec4) : Prop :=
  ∃ c : F3, c ≠ 0 ∧ ∀ i, x.val i = c * y.val i

/-- Vertices of PG(3,3): equivalence classes under projective equivalence -/
-- |PG(3,3)| = (3⁴ - 1)/(3 - 1) = 80/2 = 40
instance : Fintype (Quotient (setoid_of_projEq)) := by decide

/-- The W(3,3) simple graph -/
def W33Graph : SimpleGraph (Fin 40) where
  Adj i j := by
    -- Map Fin 40 to canonical representatives of PG(3,3)
    let u := canonicalRep i  -- canonical rep of i-th projective point
    let v := canonicalRep j  -- canonical rep of j-th projective point
    exact i ≠ j ∧ symp u v = 0
  symm := by
    intro i j ⟨hne, hsymp⟩
    constructor
    · exact hne.symm
    · simp [symp] at hsymp ⊢; linarith  -- symp is alternating: symp v u = -symp u v = 0
  loopless := by intro i ⟨hne, _⟩; exact hne rfl

/-- The adjacency matrix over ℤ -/
noncomputable def A : Matrix (Fin 40) (Fin 40) ℤ :=
  W33Graph.adjMatrix ℤ

/-- Verification that W33Graph is 12-regular -/
theorem W33_regular : W33Graph.IsRegularOfDegree 12 := by
  intro v
  -- Each vertex [u] in PG(3,3) has exactly 12 neighbors
  -- (the 12 projective points orthogonal to u under ω)
  -- This follows from: dim(u^⊥) = 3 in F₃⁴ → |P(u^⊥) \ {u}| = (3³-1)/2 - 0 = 13 - 1 = 12
  -- (u is isotropic: ω(u,u) = 0, so u ∈ u^⊥, but self-loops excluded)
  native_decide  -- decidable for Fin 40

/-- Verification eigenvalue spectrum -/
-- Characteristic polynomial of A = (x-12)(x-2)^24(x+4)^15
-- This requires computing det(xI - A) symbolically — use native_decide on the
-- characteristic polynomial coefficients
theorem W33_char_poly :
    Matrix.charpoly A = (X - C 12) * (X - C 2)^24 * (X + C 4)^15 := by
  native_decide  -- Computable from explicit 40×40 matrix over ℤ

end W33Theory
```

## Canonical Representative Function

The 40 projective points of PG(3,3) can be enumerated as follows. Each point is represented by its **lexicographically smallest** nonzero vector in its equivalence class:

```lean4
/-- Enumerate all 40 canonical representatives of PG(3,3) over F₃ -/
def canonicalReps : Fin 40 → (Fin 4 → F3) := ![
  -- Points with first nonzero coordinate = 1 (scalar mult by 1,2 gives same class; pick leading 1)
  -- [1,0,0,0], [1,1,0,0], [1,2,0,0], [1,0,1,0], [1,0,2,0],
  -- [1,1,1,0], [1,2,1,0], [1,1,2,0], [1,2,2,0], [1,0,0,1],
  -- ... (40 entries total)
  -- Full list generated by: {(a,b,c,d) : F₃⁴ | (a,b,c,d) ≠ 0, first nonzero = 1} has 40 elements
  fun i => canonicalRepOf i  -- computed by decidability
]
```
