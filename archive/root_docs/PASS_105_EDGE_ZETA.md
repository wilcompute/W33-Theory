# Pass 105: Edge Zeta (Hashimoto) Separation of 28 Spence Graphs

## Main Result: NEGATIVE (but the theorem is positive)

For a **k-regular graph**, the Hashimoto (edge) zeta is **identical to the Ihara zeta** --
both are fully determined by the adjacency spectrum (Hashimoto 1989, Bass 1992).

Since all 28 Spence SRG(40,12,2,4) share the same spectrum {12^1, 2^24, (-4)^15}, they
all have **identical Hashimoto zeta**. Edge zeta provides no new separation.

## The Positive Theorem

**The Smith critical group is strictly finer than any zeta-based invariant** for the
28 Spence SRG(40,12,2,4). The {17,8,2,1} 2-rank ladder is the finest known
polynomial-time non-isomorphism separator for this family.

This is a publishable observation: the Smith ladder transcends all spectral/zeta methods.
