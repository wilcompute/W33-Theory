## Theorem 99.1 — Construction-A Basis Template

Let `C = C_2(W) ⊂ F_2^40` with parameters `[40,16,8]`.
The even Construction-A lattice is

    Λ_C = { x / sqrt(2) : x ∈ Z^40, x mod 2 ∈ C }.

Choose a binary generator matrix `G ∈ Mat_{16×40}(F_2)` for `C`, and lift its rows to vectors
`ĝ_i ∈ {0,1}^{40} ⊂ Z^{40}`.
Then a spanning set for `Λ_C` is

    B = { sqrt(2)e_1, ..., sqrt(2)e_40, (1/sqrt(2)) ĝ_1, ..., (1/sqrt(2)) ĝ_16 }.

Hence `Λ_C` is generated by 56 canonical vectors, from which one extracts a rank-40 Z-basis by Smith/Hermite reduction.

**Meaning:** the explicit basis problem is not conceptual; it is purely linear-algebraic once the code generator matrix is known.

## Theorem 99.2 — Determinant and Discriminant Rank

For an even binary code `[n,k]`, Construction A gives

    det(Λ_C) = 2^{n-2k}.

Here `n=40`, `k=16`, so

    det(Λ_C) = 2^(40-32) = 2^8.

Therefore:

- rank(`Λ_C`) = 40,
- `Λ_C^*/Λ_C ≅ (Z/2)^8`,
- the discriminant form has F_2-dimension 8,
- Pass 92 then identifies this 8-dimensional quadratic space with `E8/2E8`.

So the explicit basis, once reduced, must produce a Gram matrix of determinant exactly `2^8`.

## Theorem 99.3 — Gram Skeleton from Code Weights

For Construction A on a doubly-even self-orthogonal code:

- `⟨sqrt(2)e_i, sqrt(2)e_j⟩ = 2δ_ij`,
- `⟨sqrt(2)e_i, ĝ_a/sqrt(2)⟩ = (ĝ_a)_i ∈ {0,1}`,
- `⟨ĝ_a/sqrt(2), ĝ_b/sqrt(2)⟩ = wt(ĝ_a ∩ ĝ_b)/2`.

Since every codeword in `C_2(W)` has weight divisible by 4 and minimum weight 8, the diagonal entries
for code lifts begin at 4 and all pairings are integral. Therefore `Λ_C` is even integral, as required.

Thus the entire Gram matrix of any explicit basis is controlled by:

1. coordinate incidence,
2. pairwise intersections of lifted generator rows,
3. a final HNF/SNF reduction step.

The lattice is therefore fully computable from the code generator matrix alone.

## Theorem 99.4 — The 255-Coset Orbit Problem

Since `Λ_C^*/Λ_C ≅ (Z/2)^8`, there are 255 nonzero discriminant cosets.
Pass 92 already splits these as:

    135 isotropic + 120 anisotropic.

Because `Aut(W(3,3)) ≅ W(E6)` acts on the code and hence on `Λ_C`, it induces an action on
`Λ_C^*/Λ_C`. Therefore the full orbit program is:

1. build the 255 nonzero cosets,
2. compute the quadratic form on each coset,
3. separate isotropic (135) from anisotropic (120),
4. compute orbit sizes under `W(E6)`.

The first forced conclusion is that the action factors through a subgroup of `O^+_8(2)` preserving
this split. So the orbit decomposition is a concrete bridge between the E6 symmetry and the E8 discriminant world.
