Research roadmap (phases)
1) Foundations: formalize core algebraic structures (3U decomposition, primitive plane,
   U1 family, A4 couplings) with reproducible computational witnesses and symbolic
   derivations where possible.
2) Validation: build a suite of deterministic checks (integer-lattice rank, Smith
   normal form, rational-span tests) that certify numerical results used in theorems.
3) Integration: connect modular-forms → lattice → E8 → Leech → Moonshine pipeline
   with a clear dataflow and checkpoints, producing machine-readable derivation artifacts.
4) Phenomenology: publish small reproducible experiments (DM mass fits, cosmic-ray
   toy models) with scripts and unit tests verifying expected outputs.
5) Communication: produce short, reviewable papers and notebooks explaining main claims,
   with reproducible figures and exact input data.

Long-term milestones
- Formal verification of key identities (e.g., lattice isomorphisms) using a symbolic
  proof assistant or computer algebra reproducible pipeline.
- Public release of datasets and Docker/VM images that reproduce main experiments.
