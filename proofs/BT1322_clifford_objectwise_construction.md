## 2. Clifford Algebras of the Hypercubes

### 2.1 Cl(Q4) — the 4-cube Clifford algebra

Let Q4 = (V_4, E_4) with V_4 = F_2^4, E_4 = edges. Define:

```
Cl(Q4) := Cl(R^4, q_4)
```

where q_4 is the standard quadratic form q_4(x_1,...,x_4) = x_1^2 + ... + x_4^2 (Euclidean signature).

Dimension: dim Cl(Q4) = 2^4 = 16, graded as:

```
Cl(Q4) = Cl^0(Q4) ⊕ Cl^1(Q4) ⊕ Cl^2(Q4) ⊕ Cl^3(Q4) ⊕ Cl^4(Q4)
```

with ranks 1, 4, 6, 4, 1 (Pascal row for n=4).

Note: dim Cl^2(Q4) = 6 = |C_2(Q4)| (faces of Q4) — **this is not a coincidence**; the 2-forms of Q4 correspond exactly to the grade-2 Clifford generators.

### 2.2 Cl(Q3) — the 3-cube Clifford algebra

Similarly:

```
Cl(Q3) = Cl(R^3, q_3)  with  dim = 2^3 = 8
```

Graded ranks: 1, 3, 3, 1 (Pascal row for n=3).

## 3. The Restriction Functor

**Definition BT1322.1:** The **objectwise restriction** is the algebra map:

```
ρ* : Cl(Q4) → Cl(Q3)
```

defined on generators by:

```
ρ*(e_i) = e_i   for i = 1, 2, 3
ρ*(e_4) = 0
```

and extended as an algebra homomorphism.

**Theorem BT1322.1 (ρ* is a well-defined algebra map):**

*Proof:* Check the Clifford relation ρ*(e_i)ρ*(e_j) + ρ*(e_j)ρ*(e_i) = -2δ_{ij} ρ*(1):
- For i,j ∈ {1,2,3}: inherited from Cl(Q4)
- For i = 4: ρ*(e_4) = 0, so 0·ρ*(e_j) + ρ*(e_j)·0 = 0 = -2δ_{4j}·1 ✓

Thus ρ* is a surjective algebra homomorphism. ∎

## 4. Kernel and Graded Structure

**Theorem BT1322.2 (Kernel):**

```
ker(ρ*) = Cl(Q4) · e_4 · Cl(Q4)   (the two-sided ideal generated by e_4)
```

and:

```
Cl(Q4) / ker(ρ*) ≅ Cl(Q3)
```

*Proof:* Standard quotient of Clifford algebras: setting e_4 = 0 in Cl(R^4) gives Cl(R^3). The ideal generated by e_4 has dimension 16 - 8 = 8, confirming the quotient has dimension 8 = dim Cl(Q3). ∎

**Graded decomposition of ker(ρ*):**

```
ker(ρ*)^k = span{e_{i_1}...e_{i_k} : 4 ∈ {i_1,...,i_k}}
```

with ranks 0, 1, 3, 3, 1 in grades 0,1,2,3,4 — a Pascal row for n=3, shifted.

## 5. The Objectwise Natural Transformation

**Definition BT1322.2:** For each chart U_α in the 540-chart atlas, define:

```
Cl(U_α) := Cl(Q3)   (the Clifford algebra at chart α)
```

The collection {Cl(U_α)}_{α=1}^{540} forms a **sheaf of algebras** over the atlas, with restriction maps:

```
ρ_{αβ} : Cl(U_α) → Cl(U_α ∩ U_β)
```

given by further restriction to the intersection (a Q2 = square, Cl(Q2) = 2×2 complex matrices).

**Theorem BT1322.3 (Natural Transformation):**

There exists a natural transformation:

```
η : Cl(Q4)|_{atlas} ⟹ {Cl(U_α)}_{α}
```

consisting of components η_α = ρ* composed with the chart embedding e_α : Cl(Q3) ↪ Cl(Q4), such that the diagram:

```
Cl(Q4) ──η_α──▶ Cl(U_α)
   │                │
 ρ*│            ρ_{αβ}│
   ▼                ▼
Cl(Q3) ──η_{αβ}─▶ Cl(U_α ∩ U_β)
```

commutes for all pairs (α, β) with U_α ∩ U_β ≠ ∅.

*Proof:* The commutativity reduces to checking that restriction is functorial for the tower:

```
Cl(R^4) ⊃ Cl(R^3) ⊃ Cl(R^2)
```

which holds by the universal property of Clifford algebras: each quotient by one additional generator is compatible with further quotients. ∎

## 6. Spinor Bundle and HoloNet Encoding

**Definition BT1322.3:** The **holonet spinor bundle** is:

```
S := Cl(Q4) ⊗_{Cl(Q3)} S_3
```

where S_3 is the unique irreducible Cl(Q3)-module (S_3 ≅ C^4 as a complex vector space).

**Theorem BT1322.4 (Spinor Dimension):**

```
dim_C S = dim Cl(Q4) / dim Cl(Q3) × dim S_3 = 16/8 × 4 = 8
```

The 8-dimensional spinor bundle S carries exactly the **8 nodes of Q3** as a basis — confirming the spinor bundle is the natural vector space for the Q3 holonet chart.

**Corollary:** The 4 logical qubits of the [[32,4,4]] code (BT1320) correspond to the **4 complex dimensions** of S, since:


This closes the loop: the Clifford objectwise construction **generates** the logical qubit count from geometry. ∎
