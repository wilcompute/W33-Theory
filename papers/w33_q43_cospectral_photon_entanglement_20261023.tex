\begin{abstract}
Two nonisomorphic generalized quadrangles of order $(3,3)$,
the symplectic $W(3,3)$ and the parabolic-quadric $Q(4,3)$,
have cospectral point-collinearity graphs on forty points,
both $\operatorname{SRG}(40,12,2,4)$. We compare a specified
two-factor single-photon \emph{mode} phase state
$|\Psi_A\rangle=40^{-1}\sum_{a,b}(-1)^{A_{ab}}|a,b\rangle$.
The states have exactly identical Schmidt probabilities and
are even related by identical real orthogonal mode changes on
both factors. Nonetheless, when coherent operations must
respect computational address labels and only local diagonal
signs are treated as free, the number of binary parity-product
cross-register couplings needed for the corresponding phase
oracle is exactly 14 for $W(3,3)$ and eight for $Q(4,3)$.
The difference corresponds to seven versus four alternating
hyperbolic pairs. Exact compilers, 4096-vector Icarus tests
for each registered oracle, and matched-toolchain
iCE40UP5K reference builds document this \emph{gate-set-dependent}
separation. This is not an experimental single-photon test,
nor a device-independent separation between quantum states.
\end{abstract}
\section{Established geometric and coding results}
We draw both adjacency matrices from existing independently
audited repository builders:
\texttt{w33\_pass76\_cospectral\_mates.py} and
\texttt{w33\_pass88\_smith\_group.py}.
The latter establishes the already-known binary adjacency
ranks $16$ and $10$, and nonisomorphism and equal adjacency
spectra had been established in earlier project passes.
These observations are not new results of this note.
External mathematical prior art treats minimal binary ranks
of strongly regular graphs and the GQ$(3,3)$ geometries;
see the bibliography.

Let $A_W,A_Q$ be their $40\times40$ zero-diagonal
adjacency matrices. Each has
\[
\operatorname{spec}(A)=
\{12^{(1)},\,2^{(24)},\,(-4)^{(15)}\}.
\]

\section{Bipartite mode entanglement cannot separate the mates}
For $G\in\{W,Q\}$, consider two \emph{operationally
independent} forty-dimensional degrees of freedom of a
single photon. Define the normalized pure-state coefficient
matrix
\[
C_G=\frac{J-2A_G}{40},\qquad
|\Psi_G\rangle=\sum_{a,b=0}^{39}(C_G)_{ab}|a\rangle|b\rangle.
\]
This physical interpretation requires an actual addressable
tensor decomposition of path, time, frequency, or other modes;
two labels do not by themselves supply two independently
accessible particles.

\begin{theorem}[Spectral blindness and local equivalence]
Both two-factor states have Schmidt probabilities
\[
\boxed{\{.16^{(1)},\ .04^{(15)},\ .01^{(24)}\}},
\]
Schmidt rank forty, purity $0.052$, and entropy
\[
H=-.16\log_2(.16)-15(.04)\log_2(.04)
  -24(.01)\log_2(.01)
 =4.803856189774729\text{ bits}.
\]
Moreover there is a real orthogonal $O\in O(40)$ with
$|\Psi_Q\rangle=(O\otimes O)|\Psi_W\rangle$.
\end{theorem}
\begin{proof}
Regularity and cospectrality imply $J$ commutes with
each adjacency matrix. $J-2A_G$ therefore has
eigenvalues $16$ (once), $-4$ (24 times), $8$
(15 times). Dividing their absolute values by
forty gives the common Schmidt coefficients.
As real symmetric matrices with the same spectrum,
$A_W,A_Q$ are orthogonally similar: choose $O$
so that $A_Q=OA_WO^{\mathsf T}$.
The $12$-eigenspace is one-dimensional and spanned
by the uniform vector, so $O\mathbf 1=\pm\mathbf 1$
and $OJO^{\mathsf T}=J$.
Thus $C_Q=OC_WO^{\mathsf T}$, exactly the
coefficient-matrix transformation under
$O\otimes O$.
\end{proof}
The software produces a numerical explicit
orthogonal witness with small residual.
No bipartite entanglement monotone can distinguish
these two pure states if unrestricted local
unitaries are allowed.

\section{The binary local-diagonal gate restriction}
A computational-basis address-controlled sign is
\[
U_G|a,b\rangle=(-1)^{(A_G)_{ab}}|a,b\rangle.
\]
Allow independent computational-basis signs
$f(a),g(b)$ and a global sign as local phase
corrections. Define the double-centered matrix
over $\mathbb F_2$ using reference address $0$:
\[
B_G(a,b)=A_G(a,b)+A_G(a,0)+A_G(0,b)+A_G(0,0).
\]
Here $A_G(0,0)=0$.
\begin{theorem}[Restricted phase-coupling optimum]
For a gate set whose cross-register entangling
resources are rank-one binary parity products
$(-1)^{u_k(a)v_k(b)}$, with local diagonal
phase tables freely permitted, the minimum
number of nonlocal binary terms is
$\operatorname{rank}_{\mathbb F_2}B_G$.
For the two geometries,
\[
\begin{array}{c|cc}
&G=W(3,3)&G=Q(4,3)\\\hline
\mathrm{rank}_{\mathbb F_2}A_G&16&10\\
\mathrm{rank}_{\mathbb F_2}B_G&14&8\\
\mathrm{alternating\ hyperbolic\ pairs}&7&4
\end{array}.
\]
\end{theorem}
\begin{proof}
For any locally compensated binary phase table
$D=A+f\mathbf1^{\mathsf T}
+\mathbf1g^{\mathsf T}
+cJ$, its double-centering is $B_G$.
Double-centering is left and right
multiplication by binary matrices,
so $\mathrm{rank}(B_G)\le\mathrm{rank}(D)$.
Every sum of $r$ separable binary parity
products has rank at most $r$. Conversely,
binary Gaussian elimination constructs
$B_G=LR^{\mathsf T}$ of rank $r=\mathrm{rank}B_G$
and the two omitted single-register phase
tables exactly restore $A_G$. The code
checks every one of the 1600 address pairs.
The computed centered matrices are symmetric
with zero diagonals, hence alternating;
successive symplectic elimination gives
\[
B_G=\sum_{k=1}^{r/2}
\left(x_ky_k^{\mathsf T}+y_kx_k^{\mathsf T}\right)
\quad(\bmod 2).
\]
In the explicit GQ builders, elimination yields
$r=14$ and $8$. Every reference address in
each graph gives the same locally centered ranks.
\end{proof}
This is \emph{not} a lower bound for arbitrary
quantum circuit libraries: an unrestricted
local $O(40)$ can interchange these two states,
and changing optical primitives or nonlocal
computing resources changes the cost model.
The 14 and eight terms are not counts of
fabricated Mach--Zehnder interferometers.

\section{Noncontiguous four-register recursion: negative control}
For four independently addressable forty-state
factors with the three nearest-neighbor
controlled signs, consider the cut $(a,c)|(b,d)$.
Let $S=J-2A$ and $H=S^2$. For
\[
|\Phi\rangle=\frac1{40^2}
\sum_{a,b,c,d}S_{ab}S_{bc}S_{cd}|a,b,c,d\rangle,
\]
the reduced density matrix on $(a,c)$ satisfies
\[
(\rho_{ac})_{(a,c),(a',c')}=
\frac{H_{cc'}}{40^4}
\sum_b S_{ab}S_{a'b}S_{bc}S_{bc'}.
\]
The exact integer contraction of
$\operatorname{tr}\rho_{ac}^2$ gives the same
\[
\boxed{\operatorname{tr}\rho_{ac}^2=0.0020128}
\]
for W and Q. In both graphs, for every ordered
nonadjacent pair $(c,c')$, the associated
signed-neighbor vector has $x^{\mathsf T}Ax=-32$.
Thus this particular four-factor
noncontiguous purity test is also blind
to the geometry. We make no general claim
for all multipartite partitions or all
entanglement monotones.

\section{Scientific implication and next falsifier}
A single photon's bipartite mode
entanglement spectrum cannot by itself
select W33 from its cospectral mate.
Even a measured two-register state entropy
matching $4.803856$ bits would be
\emph{insufficient} evidence for unique
W33 geometry, much less a theory of everything.
A meaningful optical comparison needs a fixed
address calibration, a specified restricted
gate set, real controlled phases, and measured
resource/error trade-offs; or it must use
additional operator-algebraic/contextuality
relations specific to the two-qutrit Pauli
representation of W33. The latter is a
different proposed experiment and remains open.

\section{The Q(4,3) graph is the dual forty-bus W33 architecture}
The physical W33 line-bus manifest already specifies
forty four-point lines, with four line buses through each
W33 point. A line bus is an optical address with four
internal rail slots, not a $40$-mode photon by itself.
The line-intersection adjacency
\[
D_{ij}=\begin{cases}
1&i\ne j,\quad L_i\cap L_j\ne\varnothing,\\
0&\text{otherwise}
\end{cases}
\]
has parameters $(40,12,2,4)$.
As an established geometric duality,
the point graph of $Q(4,3)$ is isomorphic
to this intersection graph of W33 lines.
Our script \texttt{analysis/w33\_linebus\_dual\_q43\_phase\_geometry\_20261023.py}
constructs and exhaustively verifies an explicit
forty-element permutation between the actual
W33 bus IDs and the independently constructed
parabolic-quadric points. It confirms binary
adjacency rank ten, locally centered phase
rank eight, and four symplectic hyperbolic
pairs \emph{in the actual line-bus address system}.
This demonstrates the dual geometry inside the
already-defined Holonet compiler; it does
not imply that intersecting abstract lines
are physically connected by coherent optical
phase gates.

\section{The cost of changing phase-oracle address bases}
We generated three Q43 registered SystemVerilog
control variants and compared them against the
previous W33 point-based controller using the
same iCE40UP5K target, Yosys mapping,
nextpnr routing seed and nominal timing request:
\begin{center}
\begin{tabular}{lrrrr}
\toprule
Classical address encoder & Cross terms & LUT4 & Logic cells & I/O\\
\midrule
W33 point native &14&172&182&34\\
Q43 canonical point IDs &8&115&125&28\\
Q43 after runtime W33 line-bus remapping &8&175&185&28\\
Q43 directly compiled for W33 line-bus IDs &8&106&116&28\\
\bottomrule
\end{tabular}
\end{center}
All three Q43 variants passed exhaustive Icarus
tests on the 1600 valid $(a,b)\in\{0,\ldots,39\}^2$
and 2496 invalid six-bit address pairs. Each
produces the oracle bit and individual
cross-product and local gauge sign flags.
The runtime address translator increases the
Q43 logic-cell cost from 125 to 185, eliminating
its apparent gain over W33's 182.
The \emph{compile-time} translator instead
permutes the eight-term lookup tables during
RTL generation and uses \textbf{116 logic cells},
36.3\% fewer than the 182-cell W33 reference.
This is a comparison of four \emph{specific
classical address-to-phase control encoders}.
It neither establishes minimal FPGA area nor
equates a phase flag with a physical optical CZ.

The complete compiled technology netlists and
unconstrained routes are archived as compressed
files in \texttt{data/}; see
\texttt{data/w33\_q43\_dual\_linebus\_phase\_oracle\_hardware\_verified\_20261023.json}.
No pin-constraint file was available,
all pads were automatically assigned, and
nextpnr reported no meaningful internal clock
frequency for these register-boundary-only
phase metadata circuits. No genuine
physical inter-bus phase coupling, time-bin
quantum memory, photonic coherence measurement,
or fundamental physical TOE conclusion
is claimed.
