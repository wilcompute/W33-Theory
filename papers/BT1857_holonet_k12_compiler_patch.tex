\[
  n=72,\qquad \text{payload}=66,\qquad \text{parity}=6,

over $\mathbb F_3$, with rate $11/12$.
\end{definition}

\begin{remark}[Claim boundary]
The compiler is a syndrome/check surface, not yet a quantum error-correcting code
distance theorem.  BT1856 falsifies the stronger claim: the raw $[72,66,6]$ incidence
compiler has minimum distance $2$ as a linear check code.  A genuine protected quantum
memory would require an additional CSS or subsystem split with independent logical and
gauge operators.
\end{remark}
