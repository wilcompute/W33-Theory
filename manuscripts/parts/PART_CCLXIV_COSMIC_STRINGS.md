# PART CCLXIV: Cosmic Strings and Topological Defects

## Magnetic Monopoles

### 't Hooft Operator

In SU(3) gauge theory, the monopole operator creates a topological charge:
$$\mathcal{M} = e^{i\oint_C A} \quad \text{around contour } C$$

The charge quantization:
$$g_m = \frac{2\pi n}{g} \quad (n \in \mathbb{Z})$$

For W(3,3) structure with $Q = 3$:
$$\text{Order of 't Hooft operator} = Q = 3$$

### Monopole Detection

Monopole loops on a high-genus surface create non-trivial cycles:
$$\oint_{\gamma} A = \text{multiple} \times 2\pi$$

For genus-6 surface (Heffter's $K_{12}$):

- **Independent loops**: $2g = 12 = k$
- **Monopole charge quantization**: Dirac quantization $n = 0, 1, ..., k-1$
- **Topological charge sectors**: Correspond to W(3,3) structure

### Charge Spectrum

The allowed monopole charges:
$$Q_m = \frac{2\pi m}{g_{\text{coupling}}} \quad (m = 0, 1, ..., k-1)$$

With $k = 12$, we have **12 distinct monopole charge sectors**.

## Cosmic Strings

### Type I Cosmic Strings

In unified field theories, cosmic strings arise from:
$$\frac{G}{U(1) \times SU(3) \times SU(2) \times U(1)_Y} \to \frac{G}{\text{electroweak}}$$

String tension:
$$\mu_{\text{string}} = \frac{\eta^2}{2\pi}$$

where $\eta$ is the symmetry-breaking scale.

### String Intersections

When cosmic strings cross, they create junctions:
$$\text{# of junctions} \sim \frac{Q}{2\pi} \times \frac{\mu_{\text{string}}}{\rho_{\text{area}}}$$

For W(3,3): $Q = 3$ independent sectors → 3 types of string intersections.

### Gravitational Wave Radiation

Cosmic string networks emit gravitational waves at frequencies:
$$f_{\text{GW}} \sim \frac{c}{L_{\text{correlation}}}$$

where $L_{\text{correlation}}$ is the typical string separation.

The **detectable strain** for strings with W(3,3) structure:
$$h \sim 10^{-18} - 10^{-15}$$

(within range of future gravitational wave detectors)

## Monopole Dynamics on High-Genus Surfaces

### Monopole Loops

On a genus-$g$ surface, there are $2g$ independent non-contractible loops:

For genus 6:
$$2g = 12 = k$$

### Loop-Winding Numbers

Monopole trajectories can wind around handles:
$$w_i = \text{winding number around handle } i$$

Total independent windings: $\sum_i w_i^2 \leq 2g = 12$

### Monopole Dissociation

When monopoles move on high-genus surfaces:

- **Far apart**: They interact via Coulomb force
- **Approach each other**: They can annihilate or create strings
- **Critical separation**: $r_c = \frac{g_m^2}{4\pi E_0}$

For W(3,3): $r_c \sim 10^{-16}$ cm (GUT scale)

## Chern-Simons Theory

### Chern-Simons Level

The topological action:
$$S_{\text{CS}} = \frac{k}{4\pi} \int \text{Tr}(A \wedge dA + \frac{2}{3} A \wedge A \wedge A)$$

For W(3,3):
$$k_{\text{CS}} = \text{LAP\_TOP} = 16$$

This is the **topological level** of the theory.

### Anyonic Statistics

In 3D Chern-Simons theory with level $k$:

- Fundamental anyons have quantum dimensions $d_\alpha \leq k$
- Fusion rules: $\alpha \times \beta = \bigoplus_\gamma N_{\alpha\beta}^\gamma \gamma$

With $k = 16$: Rich anyon spectrum supporting 16 anyon types (or fewer by fusion).

### Topological Spin

The braiding phase:
$$\theta_\alpha = e^{2\pi i (h_\alpha - c/24)}$$

where $h_\alpha$ is the conformal dimension and $c = 3k/(k+k') = 3 \times 16 / (16 + \text{level}) $.
