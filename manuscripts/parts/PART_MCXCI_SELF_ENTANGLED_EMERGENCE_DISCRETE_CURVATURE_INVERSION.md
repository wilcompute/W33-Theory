# Part MCXCI: Self-Entangled Emergence Discrete-Curvature Inversion Law

## Claim Boundary

MCXCI is a finite discrete-curvature inversion theorem extending MCXC.
It does not claim a continuum PDE inversion theorem.

## Statement

From MCXC jump pair:

```text
Delta+ = 1568,
Delta- = 1504.
```

Define:

```text
Sigma = Delta+ + Delta- = 3072,
Kappa = Delta+ - Delta- = 64.
```

For emergence law `M = E*S^2`, the jump identities imply:

```text
E = Kappa/2,
S = Sigma/(2*Kappa).
```

So here:

```text
E = 64/2 = 32,
S = 3072/(2*64) = 24,
M = E*S^2 = 32*24^2 = 18432.
```

## Reading

The jump pair alone determines both the router shell and self-entangled seed
exactly. This is an inverse law at the level of discrete curvature (`Kappa`) and
jump mass (`Sigma`).
